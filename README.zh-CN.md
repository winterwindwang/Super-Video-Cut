# Super-Video-Cut

[English](README.md) | [简体中文](README.zh-CN.md)

> 一个面向完整视频剪辑交付的 agent skill：评估参考片、规划时间线、剪辑、混音、字幕、版权把关、成片审查——用可测量的数字代替形容词。

## 为什么需要它

AI 辅助剪辑通常在三个地方出问题，这个 skill 就是围绕这三点建的。

**一、靠感觉模仿风格。** 让模型参考某条爆款来剪，它往往答"快切、有电影感"——没法执行。这里的做法是先把参考片测出来（切点、镜头时长分布、响度、色彩统计、抽帧拼图），并且每条判断必须写满五段：**观察 → 依据 → 推断 → 动作 → 置信度**。缺一段，这条评估作废。

**二、同一批素材反复分析。** 一段素材常常服务多个主题。描述按文件缓存、以内容哈希寻址，视频模型只调用**一次**，之后跨主题复用，而不是每个主题重新看一遍。

**三、版权与审查当作收尾工作。** 这里它们是交付前的闸门，不是结尾的一段免责声明。

## 环境依赖

| 依赖 | 用途 | 说明 |
| --- | --- | --- |
| `ffmpeg` + `ffprobe` | 全部客观测量、成片审查、字幕硬烧 | 在 ffmpeg 8.1.2 上实测 |
| Python 3 | `material_cache.py` | 只用标准库，无需 pip 安装 |
| `PyYAML` | 可选的 YAML 校验 | 未安装时退化为基础检查 |

缺 ffmpeg 时客观测量不可用，skill 会直接说明"只能做人工评估，无法给出可复现指标"，而不是编造数值。

## 三条红线

| # | 规则 | 理由 |
| --- | --- | --- |
| 1 | **先评估，后出片。** 用户确认评估结论前不动剪。 | 未经确认的风格判断等于返工。 |
| 2 | **先查缓存，再谈模型。** 任何素材先 `lookup`，命中即禁止重新分析。 | 同一素材跨主题复用，付两次钱是浪费。 |
| 3 | **合规与审查是交付前置。** 授权未定不剪，`qc_scan.sh` 不过不交。 | 成片发布后再修，代价远高于事前检查。 |

## 主流程

| 阶段 | 目标 | 产出 |
| --- | --- | --- |
| **M0 立项** | 锁定平台、画幅、时长、口播、是否商用、交付规格 | 需求单 |
| **M1 素材入库** | 避免为同一素材付两次模型费用 | 素材描述卡，或缓存命中结果 |
| **M2 风格评估** | 把"感觉"变成参数 | 评估表 + 风格指纹 + 一页结论 |
| **M3 剪辑方案** | 把指纹翻译成时间线 | 秒级镜头方案 |
| **M4 制作** | 剪辑、配音、字幕、调色 | 初剪与工程 |
| **M5 成片审查** | 技术与版权双闸门 | 审查表 + 检测日志 |
| **M6 反馈回流** | 从真实结果里学 | 自进化记录（仅候选） |

M2 分六步，第六步是硬停：

```
S1 合规前置 → S2 客观探测 → S3 通看两遍（一遍画面 / 一遍只听声音）
→ S4 评审 A–G 维度 → S5 一页结论 → S6 ★ 用户确认门 ★
```

维度包括 **A 剪辑手法**、**B 音效**、**C 场景**，另有 D 字幕、E 叙事、F 平台语境、**G 合规边界（强制）**。每条动作项都要打迁移标：`transferable: parameter` 或 `protected: expression`——风格与套路可学，具体镜头、台词、音乐、花字不可复制。

## 脚本

三个脚本都刻意保持低依赖，且已在真实文件上端到端验证。

```bash
SK="$HOME/.workbuddy/skills/super-video-cut"

# 一次分析，多主题复用
export MDC_HOME="$PWD/material-cache"
python "$SK/scripts/material_cache.py" lookup "素材.mp4"

# 测出参考片的客观特征
bash "$SK/scripts/reference_probe.sh" "参考片.mp4" "probe_out"

# 交付前审查成片
bash "$SK/scripts/qc_scan.sh" "成片.mp4" "qc_out"
```

`material_cache.py` 的缓存写在 `$MDC_HOME`（默认 `./material-cache`），**不会写进 skill 安装目录**。

## 证据，而非权威

库里的数字都带证据等级：**A** 标准或法规原文、**B** 厂商官方文档、**C** 学术、**D** 媒体转述。不确定的一律标"待核实"，不当作事实陈述。详见 `references/00-overview/sources-and-reliability.md`。

## 适用范围与局限

- **不构成法律意见。** 版权规则与司法口径会变，商用或高风险项目请律师复核并以官方最新文本为准。
- **平台规格会变。** 时长、码率、安全区、响度目标在不同来源间存在冲突，请"查官方文档 + 上传实测"。
- **自进化参数未经校准。** 08 卷里的阈值是自定义起始值，不是经验证的最优解。
- **约 190 项已明确标注为待核实**，每项都写明了争议点。

# 剪辑工作流与工程规范

> 分类：剪辑技巧 | 主题：素材 ingest 与校验、代理工作流、轨道组织、命名与版本、离线/在线回批、交换格式、3-2-1 备份与交付 | 整理日期：2026-11-10 | 适用：多机位剧情/纪录片/OTT 长片后期，以及 Premiere Pro / Avid Media Composer / DaVinci Resolve 之间的工程交接

## 一、核心原理

后期事故多数不是剪得不好，而是元数据丢失。Ingest 阶段第一原则是「不拿校验换速度」：存储卡必须用带校验码的工具（OffShoot、Silverstack）卸载，做 MD5 校验，确认拷贝与源逐比特一致；绝不用系统复制粘贴。DIT 同时记录 reel ID、时间码、镜头元数据与场记单（FPS / Shutter / ISO / WB / 焦距 / T 光孔 / 滤镜 / 机位高度与俯仰），这是后续 conform 与 VFX 补拍的唯一依据。

代理（proxy）工作流是离线/在线（offline / online）两段式：把 ARRI RAW、REDCODE、Sony X-OCN 等原始素材转码为编辑友好的低码率文件，剪辑在代理上完成；画面锁定（picture lock）后导出 AAF 或 XML，在 Resolve / Baselight 中重新链接原始高分辨率素材，完成在线 conform、镜头校验、重构图与终调色，最终从 master 输出。代理不是缩略图，它必须与 master 帧率完全一致、起始时间码一致、时长一致、音频声道映射一致——否则 relink 后切点会落到错误的源时间码上（混合帧率是交换格式的第一大故障源）。

交换格式各有边界：OTIO 是描述剪辑决策的 JSON（Timeline -> Stack -> Track -> Clip -> MediaReference），只存顺序、切点、转场、轨道、时长与外部媒体引用，不含媒体本身、不含渲染结果、厂商特效会塌缩为 unknown；EDL（CMX3600）只带一条视频轨、一条音频轨与基本时间码，无效果、无子剪辑；AAF 是容器而非编解码器，可能包着 MXF essence（Avid 用 OP-Atom，每条 essence 独立文件）；FCP7 XML 与 FCPXML 是两套不同 schema，OTIO 分别用 `fcp_xml` 与 `fcpx_xml` 适配器。3-2-1 备份指三份数据副本、两种不同介质、一份异地（或云），并且项目文件夹应每日压缩备份到两个独立位置。

## 二、可执行规范与参数表

工程目录（每个项目固定同一套，靠肌肉记忆找文件）：

| 目录 | 内容 | 备注 |
| --- | --- | --- |
| `01_Raw_Footage` | 原始素材，按 `Camera_A` / `Camera_B` / `Drone` / `Audio_External` 分 | 只读，永不覆盖 |
| `02_Project_Files` | 工程文件、Production / 项目锁文件 | 每日备份 |
| `03_Assets` | Graphics / Music / SFX / Stock / Brand_Kit / LUT | 字体与授权文件一并归档 |
| `04_Proxies` | 代理文件 | 与 raw 分目录、不同扩展名 |
| `05_Exports` | Review / Final / Social_Cuts | 每次导出带元数据日志 |
| `06_Deliverables` | Client / Archive、字幕、 stems、交接表 | 交付清单在此核对 |

命名与版本：

| 对象 | 格式 | 示例 |
| --- | --- | --- |
| 源素材 | `PROJ-YYYYMMDD-CAMx-SCENE-TAKE-TC` | `WILDLIFE-20231015-A01-142205-01020304.MOV` |
| 代理文件 | 源名 + `_proxy` 后缀 | `A001_C001_proxy.mov` |
| 时间线 | `PROJ_CUT_vX.Y_描述` | `PROJ_CUT_v1.1_Notes` |
| 版本 | `v1.0` / `v1.1` / `v2.0` 递增，禁用 `final` | `Project_v2.0_Approved` |
| 时间码 | `HH:MM:SS:FF`，8 位起始 `01:00:00:00` | 依据 SMPTE ST 12-1:2014 |

代理编码目标码率（Apple 官方术语表，1920x1080 / 29.97 fps）：

| 编码 | 目标码率 | 用途 |
| --- | --- | --- |
| ProRes 422 Proxy | 约 45 Mbps | 离线剪辑，全分辨率低码率 |
| ProRes 422 LT | 约 102 Mbps | 空间与带宽折中 |
| ProRes 422 | 约 147 Mbps | 一般母版 |
| ProRes 422 HQ | 约 220 Mbps | 高质量中间片 / mezzanine |
| ProRes 4444 | 约 330 Mbps | 含 Alpha 的图形交换 |
| ProRes 422 Proxy @1080p24 | 约 36 Mbps | Apple Motion 文档给出的 24p 值 |
| DNxHR LB | 待核实（未找到厂商官方码率数值） | Windows / Avid 常用代理 |

交换格式矩阵：

| NLE | 导出格式 | 注意事项 |
| --- | --- | --- |
| Premiere Pro | FCP7 XML / AAF | 与 FCPXML schema 不同，指定 `--version` |
| Final Cut Pro X | FCPXML | 媒体路径须 `file:///` 前缀 |
| DaVinci Resolve | FCPXML / AAF / EDL / OTIO（18.5 起） | DRP 为不透明二进制，往返用 FCPXML |
| Avid Media Composer | AAF + DNxHR MXF OP-Atom | 用 `-f mxf_opatom`，非 OP1a |
| Lightworks | AAF / EDL (CMX3600) | 仅切点与基本转场 |

相关规范：SMPTE ST 12-1:2014（时间码）、SMPTE 258M-2004 "For Television - Transfer of Edit Decision Lists"（CMX3600 EDL，编号写法与现行版本待核实）、AAF Object Specification v1.1（AMWA，现行版本待核实）、SMPTE ST 377-1（MXF 容器，待核实）、SMPTE ST 2067 系列（IMF，各分部编号待核实）、SMPTE ST 2110（IP 制作，Ultra HD Forum 引用）。轨道组织为工程建议配置（是否有厂商成文规范待核实）：V1-V3 主机位、V4 B-roll、V5 图形、V6 调色/调整层；A1-A2 现场对白（双单声道）、A3-A4 wild lines、A5 SFX、A6 环境声、A7 音乐、A8 mix stems。

## 三、操作步骤 / 工作流

1. **建目录与命名表**：开拍前创建上述 6 个目录与版本规则，写进 `02_Project_Files/README`。
2. **卸载 + 校验**：OffShoot / Silverstack 带 MD5 卸载，校验完成前不格式化卡。生成校验清单：

```bash
md5sum A001_C001.mov > A001_C001.mov.md5
md5sum -c A001_C001.mov.md5
ffprobe -v error -select_streams v:0 -show_entries stream=codec_name,width,height,r_frame_rate,pix_fmt:stream_tags=timecode -of default=noprint_wrappers=1 A001_C001.mov
```

3. **生成代理**：帧率、时间码、reel ID、声道映射与源完全一致；源为 4K 时按 1/2 或 1/4 尺寸试转，先做 screen test 再批量。ffmpeg 示例（`-profile:v 0` 对应 ProRes 422 Proxy 的映射需以本机 `ffmpeg -h encoder=prores_ks` 输出为准，待核实）：

```bash
ffmpeg -i A001_C001.mov -vf "scale=1920:1080" -c:v prores_ks -profile:v 0 -c:a pcm_s16le -ar 48000 -timecode 01:00:00:00 A001_C001_proxy.mov
```

NLE 内对应菜单：Premiere Pro `File > Generate Proxies` / Media Browser `Transcode to Proxy`；Resolve `Generate Proxy Media`；FCP `Transcode to Proxy`；Avid `Create Proxy Clips`。
4. **同步与建 bin**：按时间码或波形同步外录音频，建多机位序列；bin 建议 `00_INGEST_RAW` / `01_PROXY` / `02_OFFLINE_EDIT` / `03_ONLINE_MASTER`，在 `02` 内改用 `INT_KITCHEN_DAY_01_TAKE3` 之类的描述名而非原始文件名。
5. **离线剪辑**：启用代理模式；打星级 selects、paper edit 标记、radio cut（音频先行）、B-roll 分层、字幕；响度先归一到 -14 LUFS（社媒）/ -16 LUFS（LinkedIn、Twitter），广播走 EBU R128 或 ATSC A/85。
6. **画面锁定与交接**：导出 AAF（音频 conform 到 Pro Tools）与 XML/OTIO（画面 conform 到 Resolve）；OTIO 枢纽转换示例：

```bash
otio-convert --input premiere.xml --output-format fcpx_xml > resolve.fcpxml
otio-convert --input resolve.fcpxml --input-format fcpx_xml --output-format cmx_3600 > cut.edl
```

转换后核对 clip count、总时长、转场数、音频轨数与电平，并在 3 至 5 个已知时间码的切点上抽查。若 conform 后媒体路径变化，用 OTIO 的 `remap-media` 重映射。
7. **在线回批**：关闭代理 -> Relink Media / Replace with Originals 指向 `01_Raw` -> 逐镜头核对 offset、时间码、变速、缩放、重命名；Resolve 中先 conform 再调色，降噪放最后。
8. **母版输出**：禁用 Use Proxies / Proxy Export；按交付 spec 选 ProRes 422 HQ / DNxHR HQ / H.265，写入正确色彩空间标记，48 kHz / 24-bit 音频。
9. **交付清单核对**：母版 + 平台衍生版（批量队列）+ SRT 字幕 + 音频 stems + 工程文件 + 字体/授权 + LUT + EDL/XML/AAF + 校验清单 + 元数据日志。
10. **3-2-1 归档**：三份副本（共享存储 + 本地硬盘 + 异地/云），两种介质，一份异地；每日压缩项目文件夹备份到两处。

## 四、常见错误与排查

| 现象 | 根因 | 排查动作 |
| --- | --- | --- |
| relink 后切点落到错误源时间码 | 代理帧率/时间码与源不一致 | 用 ffprobe 比对起始 TC 与 `r_frame_rate`，重新生成代理 |
| 大量片段离线（media offline） | 生成代理后移动了目录；OTIO 不保存媒体本体 | 固定目录结构、用相对路径；执行 `remap-media` |
| 导入后结构丢失 | FCP7 XML 与 FCPXML 用错适配器 | 明确 `--input-format fcp_xml` / `fcpx_xml` |
| AAF 里看不到画面 | AAF 是容器，essence 可能是 MXF OP-Atom | 用 MediaInfo 检查内部；Avid 用 `-f mxf_opatom` |
| 23.976 与 29.97 DF 混剪后逐帧漂移 | 丢帧与非丢帧时间码混用 | 统一到单一 mezzanine 帧率，透传 `-timecode` |
| 特效在目标 NLE 消失 | 厂商特效不 round-trip | 预算手工重建；预渲染效果视为源 |
| 输出体积异常/画质下降 | 从代理导出（Use Proxies 未关） | 关闭代理导出，重新从 master 输出 |
| 原始素材被覆盖 | 代理与 master 同名同目录 | 分目录、不同扩展名，raw 目录设只读 |
| DRP 往返丢信息 | DRP 是不透明二进制 | 往返改用 FCPXML |
| 声道数/布局错乱 | 立体声、双单声道、5.1 混用 | ffprobe 核对声道布局，导入后逐轨验证 |

## 五、速查清单

- [ ] 开拍前 6 个目录与命名/版本规则已建
- [ ] 卸载带 MD5 校验，校验通过前不格式化卡
- [ ] 代理与源帧率、起始 TC、时长、声道映射四项一致
- [ ] 代理使用 ProRes 422 Proxy（约 45 Mbps @1080p29.97）或 DNxHR LB
- [ ] bin 结构固定，剪辑用描述名而非原始文件名
- [ ] 切换/回批前明确目标 NLE 与交换格式（AAF / FCPXML / FCP7 XML / EDL / OTIO）
- [ ] 转换后核对 clip count、总时长、转场、音轨数，抽查 3 至 5 个切点
- [ ] 在线回批关闭代理导出，从 master 输出
- [ ] 音频 48 kHz / 24-bit；社媒 -14 LUFS
- [ ] 交付含母版、衍生版、字幕、stems、工程、LUT、字体/授权、EDL/XML/AAF、校验清单
- [ ] 3-2-1：3 副本 / 2 介质 / 1 异地，项目每日双位置备份

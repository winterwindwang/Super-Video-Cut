# 调色与画质处理

> 分类：剪辑技巧 | 主题：一级/二级调色、示波器、Log 与 LUT、色彩空间与色彩管理、白平衡与肤色线、降噪锐化、HDR/SDR 转换与交付 | 整理日期：2026-11-10 | 适用：DaVinci Resolve / Baselight / Premiere Pro Lumetri 的调色与 QC 环节，以及 ffmpeg 批量色彩处理

## 一、核心原理

调色是色彩管线（color pipeline）的最后一环，但问题大多出在管线而非调色本身：每一级都要回答两个问题——素材当前在什么色彩空间与亮度曲线里，以及下一级假定它是什么。Rec.709 与 sRGB 的原色和 D65 白点完全相同，差别只在传递函数（BT.1886 参考显示约 2.4 gamma，sRGB 约 2.2）；这就是同一文件在 QuickTime / 浏览器里偏亮发灰、在调色软件里正常的根源。Log 是 scene-referred（描述场景光），Rec.709 是 display-referred（描述显示输出），二者之间必须做显式转换，不能靠猜。

一级调色（primary）作用于全画面：白平衡、曝光/黑位、对比、饱和度，目标是镜头之间中性一致。二级调色（secondary）作用于限定区域：用窗口（window）、HSL qualifier、跟踪把肤色、天空、某个物体单独拎出来。顺序不可违背：先中性、后风格；先镜头匹配、再套 look LUT；降噪与锐化放末级。技术 LUT（把 Log 转到显示空间）与风格 LUT 是两类东西，不能互替，索尼的 LUT 套到佳能素材上没有意义。

色彩管理用 ACES 或厂商 RCM：IDT 把各摄影机素材送入统一空间 -> 工作空间 ACEScct（准对数、带 toe，适合调色）/ ACEScg（线性、适合 VFX）-> ODT 渲染到 Rec.709 / P3 / HDR；ACES2065-1 是交换与归档编码（SMPTE ST 2065-1:2021）。PQ 是绝对亮度编码（SMPTE ST 2084:2014，0 至 10000 cd/m²），HLG 是相对编码、可向下兼容 SDR 广播；二者都在 ITU-R BT.2100 定义的 HDR 电视体系内，容器色域为 Rec.2020。示波器把「感觉」变成数据：波形图看亮度分布、矢量示波器看色相与饱和度、RGB Parade 看三通道平衡、直方图看整体曝光与削波。

HDR 标称电平（Report ITU-R BT.2408，1000 cd/m² 标称峰值显示）：

| 对象 | 标称亮度 cd/m² | %PQ | %HLG |
| --- | --- | --- | --- |
| 18% 灰卡 | 26 | 38 | 38 |
| 83% 灰阶上限 | 162 | 56 | 71 |
| 90% 灰阶上限 | 179 | 57 | 73 |
| HDR Reference White / diffuse white / Graphics White (100%) | 203 | 58 | 75 |
| 峰值白 | 约 5 倍漫射白 | - | - |

波形上 58% PQ 或 75% HLG 是参考白标记位，给高光留 headroom；18% 灰卡最接近肤色、且不受 SDR 摄影机拐点影响，是多机位对齐的锚点。HDR 制作至少 10 bit；8-bit SDR 上变换到 HDR 会放大高光并出现 banding。PQ 与 HLG 之间必须做 conversion 而非 transcode（BT.2390 第 7 节 / BT.2408-1 第 6 节），选 HLG 参考峰值 1000 cd/m² 并把 PQ 限制到同一峰值以取得一致亮度。

交付规范：

| 项目 | SDR | HDR |
| --- | --- | --- |
| 色域 / 传递函数 | Rec.709 / BT.1886 (~2.4) | Rec.2020 容器 / PQ (ST 2084) 或 HLG |
| 亮度范围 | 0 至 100 IRE（约 100 nit） | 1000 至 4000 nit 母版监视器 |
| 位深 / 采样 | 8 或 10 bit，4:2:0/4:2:2 | >= 10 bit |
| 映射方式 | - | display-referred（保外观）/ scene-referred（匹配摄影机） |
| 音频 | 48 kHz / 24-bit；-14 LUFS 社媒，EBU R128 / ATSC A/85 广播 | 同左 |

## 三、操作步骤 / 工作流

1. **先确认交付 spec**：SDR 还是 HDR、色域、gamma、峰值亮度、位深、码率、响度；HDR 必须在能显示目标范围的参考监视器与受控环境中做，笔记本开 HDR 不算参考。
2. **配置色彩管理**：Resolve 用 RCM 或 ACES，为每台摄影机选对应 IDT；工作空间 ACEScct，输出 ODT 按交付选。
3. **一级**：先白平衡（灰卡 + 矢量示波器肤色线，用 temperature/tint 修，不要用降饱和掩盖色偏）-> 曝光（波形图黑位/白位）-> 对比 -> 饱和。
4. **镜头匹配**：切到 RGB Parade，逐镜头比对，把相邻镜头亮度差压到 <= 10 IRE、色相角差 <= 10 至 15 度。
5. **二级**：用 window / qualifier 只框选面部再读肤色线（整帧会被绿墙、红衣主导）；对肤色做 hue 旋转而非整体降饱和。
6. **风格**：中性平衡完成后再套统一 look LUT 或节点树。
7. **降噪与锐化**：末级先降噪后锐化，避免先锐化放大噪声。
8. **格式转换**：HDR -> SDR 用色调映射，SDR -> HDR 注意 8-bit 高光 banding；PQ <-> HLG 走 BT.2390 转换。
9. **输出打标与 QC**：写入 `-color_primaries` / `-color_trc` / `-colorspace`，用 signalstats 复核 YMIN/YMAX，检查 full/limited range 标记。

```bash
ffprobe -v error -select_streams v:0 -show_entries stream=color_space,color_transfer,color_primaries,pix_fmt -of default=noprint_wrappers=1 input.mp4
ffmpeg -i input.mp4 -vf "signalstats,metadata=print:key=lavfi.signalstats.YMAX" -f null -
```

HDR10 (PQ) -> SDR Rec.709，需 `--enable-libzimg` 编译的 zscale：

```bash
ffmpeg -i input_hdr.mp4 -vf "zscale=t=linear:npl=100,format=gbrpf32le,zscale=p=bt709,tonemap=hable:desat=0,zscale=t=bt709:m=bt709:r=tv,format=yuv420p" -c:v libx264 -crf 18 -preset slow -c:a copy output_sdr.mp4
```

`smpte2084` 表示 PQ/HDR10，`arib-std-b67` 表示 HLG，`bt2020nc` 表示 BT.2020 非恒定亮度。tonemap 可选 `hable`（细节最好）、`reinhard`（整体亮）、`mobius`（折中）、`bt.2390`（ITU 标准、广播默认）；`npl=100` 为 SDR 参考峰值，1000 nit 源可试 `npl=1000`。

## 四、常见错误与排查

| 现象 | 根因 | 排查动作 |
| --- | --- | --- |
| 导出在 QuickTime / 浏览器发灰 | Rec.709 2.4 与 sRGB 2.2 传递函数差异，或色彩标记缺失 | 写入正确 color_trc / color_primaries；在消费者屏复核 |
| 同一 grade 在两台机器不同 | 监视器漂移 / 未校准 | 校准到 D65、BT.1886 2.4、暗室参考环境 |
| HDR 直接重编码后发灰泛白 | 缺 tonemap，PQ 值被当 SDR 读 | 用 zscale + tonemap 链路，末端 re-tag BT.709 |
| 肤色偏青/偏品 | 白平衡或荧光灯绿溢 | 用 temperature/tint 修，不要降饱和；框选面部读 123 度线 |
| 矢量示波器读数不可信 | 整帧被背景/衣服色彩主导 | 用 window 或 qualifier 只框面部 |
| 风格 LUT 放大了色温差 | 未做中性平衡就套 LUT | 回到第 3、4 步重做 |
| HDR 渐变出现 banding | 8-bit SDR 上变换 + 高光扩展 | 保持 >= 10 bit，谨慎上变换 |
| PQ/HLG 转换后亮度不一致 | 做了 transcode 而非 conversion | 按 BT.2390 转换，统一 1000 cd/m² 参考峰值 |
| 相邻镜头切一次「泵」一下 | 亮度/色相/饱和度差超阈值 | 逐镜头按 10 IRE / 10 至 15 度 / 10 至 15% 对齐 |
| zscale 不存在 | ffmpeg 未带 libzimg | `ffmpeg -filters \| grep zscale`；或改用 libplacebo（需 Vulkan） |

## 五、速查清单

- [ ] 交付 spec（SDR/HDR、色域、gamma、nit、位深）已书面确认
- [ ] 色彩管理已配置，每台摄影机 IDT 正确
- [ ] 顺序：白平衡 -> 曝光 -> 对比 -> 镜头匹配 -> 二级 -> 风格 LUT -> 降噪 -> 锐化
- [ ] 波形：0 IRE 黑位、<= 100 IRE 白位、中灰 45 至 50 IRE
- [ ] 肤色落在 123 度肤色线，且只框选面部判读
- [ ] 相邻镜头亮度差 <= 10 IRE、色相角差 <= 10 至 15 度、饱和度差 <= 10 至 15%
- [ ] HDR：203 cd/m² = 58% PQ = 75% HLG 参考白，>= 10 bit
- [ ] HDR -> SDR 使用 tonemap；PQ <-> HLG 使用 BT.2390 转换
- [ ] 输出写入 color_primaries / color_trc / colorspace，range 标记正确
- [ ] signalstats 复核 YMIN / YMAX，48 kHz / 24-bit 音频，响度符合交付

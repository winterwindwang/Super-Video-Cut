# 音频后期与混音规范

> 分类：配音与音频 | 主题：人声处理链、EQ/压缩参数与 EBU R128 / ATSC A/85 响度合规 | 整理日期：2026-11-10 | 适用：视频成片混音、广播/流媒体交付、交付前响度测量与合规验收

## 一、核心原理

**处理链顺序的原则是「先减法、后加法、响度最后锁」**：先做修复类减法（去混响、降噪、去齿音），避免后续压缩把噪声一并放大；再做音色塑形（修正性 EQ，以衰减为主）；然后压缩控制动态；最后做响度归一化，把整段节目锁定到目标 LUFS。任何一级顺序颠倒都会放大前一级的缺陷。

**响度测量的原理**：ITU-R BS.1770 用 K-weighting 逼近人耳主观感受——先经前置滤波器（高频 shelf 约 +4 dB，模拟头部声学效应），再经 RLB 高通滤除约 38 Hz 以下次低频。测量分 Momentary（400 ms）、Short-term（3 s）、Integrated（全程）三种时间窗，简称 M/S/I；400 ms 分块、75% 重叠。Integrated 采用两级门限：绝对门限 -70 LKFS 先剔除静音，相对门限再剔除比无门限响度低 10 LU 的段落（即 **-10 LU 相对门限**），避免长停顿把平均值拉低。声道权重为 L/R/C 单位增益、环绕 Ls/Rs 加 1.5 dB、LFE 不计入。True Peak（dBTP）通过 4 倍过采样估计样本间峰值，防止有损编码后削波。

**三个单位必须分清（BBC WHP202 明确）**：
- **LUFS / LKFS 完全等价**：同一把 BS.1770 表，EBU 文档写 LUFS，ATSC/ITU 与多数美规写 LKFS；-24 LKFS = -24 LUFS。
- **LUFS 是绝对响度级**（相对满刻度），**LU 是相对差值单位**：-23 到 -21 是"差 2 LU"，不是"2 LUFS"。
- **1 LU = 1 dB**：施加 +1 dB 增益，响度级升 1 LU。1 kHz 立体声正弦在 -18 dBFS 时读作 -18 LUFS。

响度标准存在的意义是终结「响度战争」：峰值归一化导致节目间响度跳变，EBU R128 与 ATSC A/85 改用感知响度归一化；美国 CALM Act 更以法规强制广告与节目响度一致。

## 二、可执行规范与参数表

### 表 1 人声处理链顺序与参数区间（工程经验值，待核实）

| 序 | 环节 | ffmpeg 滤镜 | 关键参数区间 | 作用 |
| --- | --- | --- | --- | --- |
| 0 | 去混响 | 无原生滤镜（外部插件，待核实） | 语音棚 RT60 <=0.3 s | 先修复房间反射 |
| 1 | 降噪 | `afftdn` | `nf=-25`（噪声基底 dB），强度 30%-50% | 减法，过强有金属/水下伪影 |
| 2 | 高通 | `highpass` | 80-100 Hz | 去隆隆声与低频 mud |
| 3 | 去齿音 | `deesser` | `i=0.3-0.6` `m=0.5` `f=0.5` | 压 5-9 kHz 的 s/sh |
| 4 | 修正 EQ | `equalizer` | 200-500 Hz 减 2-4 dB；3-5 kHz 加 1-2 dB | 先衰减浑浊、后提临场 |
| 5 | 压缩 | `acompressor` | ratio 2:1-4:1，attack 10-30 ms，release 100-300 ms | GR 目标 3-6 dB，不超 10 dB |
| 6 | 响度 | `loudnorm` | 按平台目标 I / TP / LRA | 双遍 linear 才合规 |

> 实测 `deesser` 选项：`i`（强度 0-1，默认 0）、`m`（最大去齿量 0-1，默认 0.5）、`f`（频率 0-1，默认 0.5）、`s`（o/i/e 输出模式）。`acompressor` 选项：`threshold`(0.00098-1)、`ratio`(1-20)、`attack`(0.01-2000 ms)、`release`(0.01-9000 ms)、`knee`(1-8，默认 2.83)、`makeup`(1-64)。

## 三、操作步骤 / 工作流（命令经本机 ffmpeg 8.1.2 实测）

### Step 1 完整人声处理链
```
ffmpeg -i raw.wav -af "highpass=f=80,afftdn=nf=-25,deesser=i=0.4:m=0.5,equalizer=f=300:t=q:w=1:g=-2,acompressor=threshold=0.1:ratio=3:attack=20:release=200,loudnorm=I=-23:TP=-1:LRA=7" -ar 48000 -ac 1 -c:a pcm_s24le vo.wav
```

### Step 2 测量（交付前必做）
```
ffmpeg -hide_banner -i mix.wav -af "ebur128=peak=true" -f null - 2>&1
```
Summary 打印 Integrated loudness / Threshold / LRA / True peak。本机实测 1 kHz 正弦：I=-21.1 LUFS、Threshold=-31.1 LUFS、Peak=-18.1 dBFS——Threshold 恰为 I 减 10 LU，印证 -10 LU 相对门限。

机器可读测量（双遍第一遍）：
```
ffmpeg -hide_banner -i mix.wav -af "loudnorm=I=-23:TP=-1:LRA=7:print_format=json" -f null - 2>&1
```
返回 `input_i` / `input_tp` / `input_lra` / `input_thresh` / `output_i` / `output_tp` / `output_lra` / `output_thresh` / `normalization_type` / `target_offset`。

### Step 3 双遍线性归一化（合规交付唯一推荐）
```
ffmpeg -i mix.wav -af "loudnorm=I=-23:TP=-1:LRA=7:measured_I=-21.05:measured_TP=-18.06:measured_LRA=0.00:measured_thresh=-31.05:offset=0.05:linear=true" -ar 48000 -c:a pcm_s24le out_ebu.wav
```
把 Step 2 的 `input_*` 填入 `measured_*`、`target_offset` 填入 `offset`。本机实测输出 -23.1 LUFS、Linear、48000 Hz。ATSC 用 `I=-24:TP=-2`；流媒体用 `I=-14:TP=-1:LRA=11`。

> **关键坑**：`loudnorm` 动态模式默认把输出写成 **192000 Hz**（本机实测），必须显式 `-ar 48000`；单遍动态模式会压缩音色且偏差约 5%-10%，不可用于合同交付。

### Step 4 Ducking / 侧链
```
ffmpeg -i music.wav -i vo.wav -filter_complex "[0:a][1:a]sidechaincompress=threshold=0.05:ratio=4:attack=10:release=300[ducked]" -map "[ducked]" -ar 48000 -c:a pcm_s24le music_ducked.wav
```
main 为音乐、sidechain 为对白；输出为被压低的音乐，再与对白 amix。

### Step 5 交付前测量与合规容差
1. 测**整段**（第一帧到最后一帧）的 Integrated I，不是 Short-term 峰值。
2. I 落在目标 ± 容差内；True Peak 低于上限；否则用线性增益 `volume=XdB`（X = 目标 - 实测）或双遍 linear 修正。
3. 若增益导致 TP 超限，用**限制器**在 -2.3 dBFS 附近限幅，而不是整体降音量。
4. 所有 deliverable（含 stereo fold-down、M&E、各语言轨）逐一测量并独立归一化。
5. 把 measured 值写入交付说明/元数据；多语种每条音轨独立达标。

## 四、常见错误与排查

| 错误 | 后果 | 处理 |
| --- | --- | --- |
| 用峰值归一化代替响度归一化 | 节目间响度跳变 | 一律用 BS.1770 响度表 |
| 混淆 LUFS 与 LU | 单位/沟通错误 | 绝对级用 LUFS，差值用 LU |
| 单遍 loudnorm 用于合规交付 | 偏差大且压缩音色 | 双遍 + `linear=true` |
| 忘记 `-ar 48000` | 输出 192 kHz，交付被拒 | 显式指定采样率 |
| TP 设 0 dBTP | 有损编码后削波 | 设 -1 / -2 dBTP |
| 处理链顺序颠倒（先压缩后降噪） | 噪声被放大 | 先减法后加法 |
| 对白/音乐频段打架靠猛 ducking | 需 >10 dB 仍听不清 | 换曲，或频段选择性 EQ |
| 重复归一化 | 动态被反复压扁 | 先测再处理，只做一次 |
| 只测主语言轨 | 多语种响度不一致 | 每轨独立归一化 |
| 用 Short-term 峰值代替 Integrated | 交付不合规 | 测全程 I |

## 五、速查清单

- [ ] 处理链顺序：去混响→降噪→高通→去齿音→修正 EQ→压缩→响度
- [ ] 降噪强度 <=50%，压缩 GR 3-6 dB、ratio <=4:1
- [ ] 明确交付目标：广播 -23 LUFS / -24 LKFS，流媒体 -14 / -16 LUFS
- [ ] 用 `ebur128=peak=true` 测整段 I、LRA、True Peak
- [ ] 合规交付用双遍 `linear=true`，并加 `-ar 48000`
- [ ] True Peak：EBU <= -1 dBTP、ATSC <= -2 dBTP
- [ ] 对白为锚点，音乐低 6-12 dB，Ducking 2-6 dB
- [ ] 所有音轨、fold-down、M&E 逐一测量，记录 measured 值
- [ ] 区分 LUFS（绝对）与 LU（差值），LKFS 视同 LUFS

# 字幕规范与排版

> 分类：字幕系统 | 主题：字幕规范与排版 | 整理日期：2026-11-10 | 适用：字幕打轴、翻译、排版与交付前 QC 的统一基线

## 一、核心原理与概念对比

字幕是限时且分心的阅读，规范围绕三条带宽约束建立：

| 约束维度 | 控制的物理量 | 失控后的表现 |
| --- | --- | --- |
| 行纪律 | 每行字数、行数、断句位置 | 三行压住画面下部、断在词组中间、语义被劈开 |
| 时间纪律 | 停留时长、切换间隔、阅读速度 | 闪字来不及读、字幕滞留、与镜头切换打架 |
| 空间纪律 | 安全区、对比度、字号、描边 | 被平台按钮遮挡、亮背景上看不清、边缘裁字 |

三类屏幕文字的规范并不通用：

| 类型 | 定义 | 是否受 CPS 约束 | 处理要点 |
| --- | --- | --- | --- |
| 对白字幕 | 人物对白、旁白的文字化 | 是 | 走本文全部规范 |
| 片中字幕 / 强制叙事 | 路牌、屏幕文字、标题卡、画外音翻译 | 是，但单独成条 | 不得与对白混在同一条事件里；需避开画面已有文字 |
| 标题 / 花字 | 片头、章节卡、节目包装字 | 否 | 字号可放大，但仍受安全区与对比度约束 |

三家公开规范的取向差异（决定了参数不能直接互相套用）：

| 规范 | 面向场景 | 计量单位 | 核心诉求 |
| --- | --- | --- | --- |
| Netflix Timed Text Style Guide, TTSG | 流媒体多语言交付 | 字符/秒 CPS | 分语言设定、机器 QC 自动拦截 |
| BBC Subtitle Guidelines | 广播与 iPlayer | 词/分钟 wpm | 逐字为准、语速上限、在线画幅适配 |
| DCMP Captioning Key | 教育媒体无障碍 | 词/分钟 wpm | 听障等效、说话人标识与音效描述 |

## 二、可执行规范与参数表

### 2.1 阅读速度与停留时长（三家对照）

| 指标 | Netflix 英语成人 | BBC | DCMP |
| --- | --- | --- | --- |
| 阅读速度上限 | 20 CPS（成人）/ 17 CPS（儿童）「待核实」 | 160-180 wpm | 130 wpm（低年级）/ 140（中级）/ 160（高年级） |
| 每行上限 | 42 字符 | 约 37 字符（图文电视等宽） | 未规定字符数 |
| 行数上限 | 2 行，优先 1 行 | 2 行（横屏 / 方形） | 2 行为宜，必要时 3-4 行 |
| 最短停留 | 5/6 秒（24fps 约 20 帧，约 833 ms） | 每词约 0.3 秒 | 40 帧（1 秒 10 帧，约 1.33 秒） |
| 最长停留 | 7 秒 | 视语境，避免节奏忽长忽短 | 6 秒（背景音乐符号除外） |
| 事件间最小间隙 | 2 帧（任何帧率） | 语音停顿处约 1.5 秒「待核实」 | 借 15 帧（约 0.5 秒）技巧调速 |

Netflix CPS 在二手资料里分歧明显（成人 17 / 20 / 20-25 CPS、儿童 13 / 17 CPS，且分语言、分 SDH 与翻译字幕），**均标注「待核实」，交付前以 Netflix Partner Help Center 对应语种 TTSG 原文为准**；本表取被引用最多的英语成人 20 / 儿童 17 为工作基线。CPS 计数含空格与标点、不含换行。

### 2.2 中英差异与每行字数

| 语言 | 计量方式 | 单行建议上限 | 竖屏 9:16 建议 | 阅读速度参考 |
| --- | --- | --- | --- | --- |
| 英文等拉丁字母 | 字符数 | 42 字符 | 约 25 字符 | 17-20 CPS |
| 中文 | 汉字个数 | 12-18 字（实务）；Netflix 繁中 16 字 / SDH 18 字「待核实」 | 10-14 字 | 约 7-9 字/秒「待核实」 |

中文信息密度高、无词间空格，不能照搬 42 字符与 20 CPS。中文 CPS 有 4-6 与 7-9 字/秒两种口径，**「待核实」**；建议以「单条 ≥ 1 秒、每行 ≤ 16 字」为硬约束。双语上下堆叠共 2 行，中文 14-16 字、英文 ≤ 8 词，切分时同时检查两行以免头重脚轻。

### 2.3 断句与语义完整

断句优先级：**语义完整 > 语法边界 > 标点 > 长度约束**。可执行的切分顺序：先按标点切 → 再对超长句按从句、意群二次切 → 最后用词级时间戳对齐语音。禁止的断行：拆开修饰语与中心词、拆开介词短语、把人名与头衔分到两行、在连词后断行、把助动词与其修饰词分行、把上句结尾与新句开头塞进同一行。字幕应在从句级别切分，不能把一句话随意劈成两半；双人对话 Netflix 用连字符分行，DCMP 则倾向把字幕放到各自说话人下方并禁止用连字符充当说话人标识（**两家规定冲突，按交付对象择一，标注「待核实」**）。跨两条字幕的延续句，停顿短于 2 秒不加省略号，停顿更长或话语拖尾才用；Netflix 指定单个 U+2026 省略号字符而非三个句点。

### 2.4 切换间隔与帧级对齐

| 项目 | 参数 | 来源 |
| --- | --- | --- |
| 相邻字幕最小间隙 | ≥ 2 帧；3-11 帧的空隙收敛到恰好 2 帧 | Netflix TTSG |
| 与音频同步误差 | 3 帧以内；出点最多延后到音频结束后 12 帧 | Netflix 交付说明「待核实」 |
| 镜头切换 | 字幕不得跨 shot change | Netflix 交付说明「待核实」 |
| 入点 / 出点实操 | 入点对准发音起始波形，出点延后 0.2-0.3 秒；整体音画差 ≤ 0.1 秒 | 国内制作实务「待核实」 |

### 2.5 安全区与竖屏适配

| 场景 | 文本块宽度 | 字高（占画面高） | 行数 | 底部留白 |
| --- | --- | --- | --- | --- |
| 横屏 16:9 | 约 68% 画宽 | 7%-8%（1080p 约 76-86 px） | 2 行 | 距底部 8%-12% |
| 竖屏 9:16 | 约 90% 画宽 | 3.9%-4.5%（1920 高约 75-86 px） | 最多 3 行 | 距底部 15%-25% |
| 电视播出 | 左右各留 18% | — | 2 行 | 上下各留 12% |

上表 BBC 的 68% / 90% / 7-8% / 3.9-4.5% 与电视、院线安全区均来自二次整理，**「待核实」**。竖屏必须避开顶部状态条、底部三分之一（评论与按钮区）、右侧图标列。对比度按 WCAG 2.2 SC 1.4.3：普通文字 ≥ 4.5:1、大文字 ≥ 3:1；硬烧文字属 images of text 同样适用，须检查运动背景里最差的一帧。

### 2.6 字体、字号、描边、阴影、背景板参数

以下为 1080p / PlayResY=1080 的 ASS 与 ffmpeg `force_style` 可直接落地的起始值：

| 参数 | 建议值 | 说明 |
| --- | --- | --- |
| FontName | 思源黑体 / 微软雅黑 / Arial / Verdana | 中粗、无衬线、比例间距、宽字面；避免细体与装饰体 |
| FontSize | 48-60（PlayResY 1080） | 相当于画面高约 5%-6%，可按 2.5 节字高校准 |
| PrimaryColour | &H00FFFFFF | 纯白（ASS 为 &HAABBGGRR 格式） |
| OutlineColour | &H00000000 | 描边纯黑 |
| Outline / Shadow | 2-3 / 1-2 | 亮背景必开，DCMP 建议叠加半透明背景框 |
| BorderStyle | 1（描边+阴影）或 3（不透明背景框） | 3 的具体渲染差异「待核实」，以播放器实测为准 |
| Alignment | 2 | 底部居中；顶部用 8 |
| MarginV / MarginL / MarginR | 40-60 / 画宽 10% / 画宽 10% | 保证边缘不裁字 |
| Bold / Italic | 0 / 仅画外音、强调、内心 OS 用斜体 | 大小写混排，禁止全大写表强调（尖叫除外） |

双语建议英文次行缩到约 80% 字号，字体风格一致（中文黑体 + 英文 Arial/Roboto）。

### 2.7 标点与数字规范

中文对话字幕统一全角标点；句尾不加句号，行尾与句尾不加逗号或顿号，保留 ?, !, …；外语与数字内容用对应半角标点。汉字与英文/数字之间加一个空格。Netflix 繁中指南明确全篇不用句号「。」，该细则属平台明文规范但本次未直接核到官方原文，**标注「待核实」**。数字、日期、时段、百分比、金额按全片统一格式（如「1000 万」不要写成「1000W」）；Netflix 规定对白中提到的币种保持原币种不换算。US 英语用双连字符表示打断、UK 英语用省略号，**属硬规范差异，勿混用**。禁用 emoji、网络乱码与自造符号。

### 2.8 片中字幕与标题区分

片中字幕（forced narrative）作为独立事件或轨道，标注位置数据以免遮挡画面已有文字，不得与对白同条。标题不受 CPS 与 2 行约束，但仍须满足安全区与对比度；标题与字幕用不同样式层，便于开关与审片。

## 三、操作步骤与工作流

定基线（画幅 / 帧率 / 交付对象）→ 按 2.3 断句生成无样式 SRT 草稿 → 用词级时间戳定时并套用最短/最长停留与 2 帧间隙 → 转 ASS 编辑 `[V4+ Styles]`（参数取 2.6）→ 硬烧预览最差帧并跑自动 QC。

可运行命令（本机 ffmpeg 8.1.2 已实测通过）：

```bash
# SRT 转 ASS 后编辑样式；ffmpeg 生成的 PlayRes 默认未必等于视频分辨率，需手工改成实际值
ffmpeg -y -i subs.srt subs.ass

# 用 force_style 覆盖样式硬烧预览；Windows 盘符冒号必须转义为 \:
ffmpeg -y -i input.mp4 -vf "subtitles='F\:/work/subs.srt':force_style='FontName=Microsoft YaHei,FontSize=54,PrimaryColour=&H00FFFFFF,OutlineColour=&H00000000,Outline=2,Shadow=1,Alignment=2,MarginV=50'" -c:v libx264 -c:a copy preview.mp4

# ASS 特效字幕用专用过滤器，保留文件内全部样式
ffmpeg -y -i input.mp4 -vf "ass='F\:/work/subs.ass'" -c:v libx264 -c:a copy preview_ass.mp4
```

CPS 自检脚本思路（标准库即可运行，输出超标事件号）：

```python
import re, sys
# 读 SRT，按空行切块；CPS = 去掉标记后的字符数 / 时长(秒)
pat = re.compile(r"(\d\d):(\d\d):(\d\d),(\d\d\d) --> (\d\d):(\d\d):(\d\d),(\d\d\d)")
def ms(h, m, s, x): return ((int(h)*3600 + int(m)*60 + int(s))*1000 + int(x))
blocks = open(sys.argv[1], encoding="utf-8-sig").read().strip().split("\n\n")
limit = float(sys.argv[2]) if len(sys.argv) > 2 else 20.0
for i, b in enumerate(blocks, 1):
    lines = b.splitlines()
    m = pat.search(b)
    if not m: continue
    dur = (ms(*m.group(5,6,7,8)) - ms(*m.group(1,2,3,4))) / 1000.0
    text = re.sub(r"<[^>]+>|\{\\[^}]*\}", "", " ".join(lines[2:])).replace("\n", "")
    cps = len(text) / dur if dur > 0 else 999
    if cps > limit or dur < 0.833 or dur > 7.0:
        print(f"#{i} dur={dur:.2f}s cps={cps:.1f} :: {text[:40]}")
```

## 四、常见错误与排查

| 现象 | 根因 | 修复 |
| --- | --- | --- |
| 闪字 | 停留 < 5/6 秒或 0.83 秒 | 延长停留或合并事件，不要靠加速时间轴 |
| CPS 超标 | 文字太长而时长太短 | 拆行 / 精简冗余词，压缩时长只会更糟 |
| 字幕滞留 | 单条 > 7 秒 | 拆分事件，出点对齐语音结束 |
| 字幕跨镜头切换 | 打轴未看切点 | 在切点前 2 帧收尾，切点后另起事件 |
| 亮背景看不清 | 无描边 / 无背景板 | 补 Outline 2-3 或半透明底板，核 4.5:1 |
| 竖屏底部被按钮挡 | 用了横屏 MarginV | 上移到画面中部，底部留 15%-25% |
| 双语头重脚轻 | 两行分别按单语上限写 | 中英一起切分，中文 14-16 字 / 英文 ≤ 8 词 |
| 句尾出现「。」或行尾逗号 | 照搬书面文稿 | 字幕去句末句号、行尾去逗号顿号 |
| 标点前多空格 / 中英标点混用 | 复制粘贴 | 统一全角标点，去除标点前空格 |
| 片中字幕与对白叠一起 | 混在同一事件 | 拆成独立事件并加位置标签 |

## 五、速查清单

- [ ] 画幅、帧率、交付规范已锁定，CPS 上限写进工程配置
- [ ] 每行 ≤ 42 字符（英文）/ ≤ 16 字（中文），最多 2 行，优先单行
- [ ] 单条停留 5/6 秒 - 7 秒，间隔 ≥ 2 帧，不跨镜头切换
- [ ] 断句在从句边界，未拆开词组、人名、介词短语
- [ ] 双语上下两行长度均衡，中文主行在前
- [ ] 白字 + 黑描边 + 阴影 / 半透明底板，对比度 ≥ 4.5:1
- [ ] 竖屏已避开顶部条、底部 1/3、右侧按钮列
- [ ] 句尾无句号，行尾无逗号顿号，数字与币种格式全片统一
- [ ] 片中字幕独立成条，标题与对白样式分离
- [ ] 所有「待核实」数值已按最终交付平台官方指南复核

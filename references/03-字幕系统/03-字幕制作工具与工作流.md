# 字幕制作工具与工作流

> 分类：字幕系统 | 主题：字幕制作工具、语音转写、强制对齐、ffmpeg 封装与质检 | 整理日期：2026-11-10 | 适用：从原始音视频到可交付字幕文件的全流程搭建

## 一、核心原理与概念对比

一条可交付的字幕链路固定经过七个阶段，工具选型本质是**在每个阶段选一个最合适的执行者**，而不是找一款软件做完全部事情：

| 阶段 | 输入 → 输出 | 主力工具 | 验收点 |
| --- | --- | --- | --- |
| ① 抽音频 | 视频 → 16k 单声道 WAV | ffmpeg | 采样率/声道正确 |
| ② 语音转写 ASR | 音频 → 带时间戳文本 | Whisper / faster-whisper / 剪映 | 文字准确率、专名与数字 |
| ③ 强制对齐 | 已知文稿 + 音频 → 词级时间戳 | WhisperX / MFA / stable-ts | 词边界精度 |
| ④ 断句与打轴 | 长文本 → 规范字幕事件 | Aegisub / Subtitle Edit / Arctime | 语义完整、CPS 达标 |
| ⑤ 人工校对 | 草稿 → 定稿 | 三级校对流程 | 错字、否定词、术语 |
| ⑥ 样式与翻译 | 定稿 → ASS / 双语 | Aegisub / Subtitle Edit | 样式一致、双行均衡 |
| ⑦ 封装 / 压制 / QC | 字幕 → 成片 | ffmpeg + 质检脚本 | 轨道、编码、语言标签 |

**ASR 与强制对齐是两件事**，混用会得到错误预期：

| 维度 | ASR（转写） | Forced Alignment（强制对齐） |
| --- | --- | --- |
| 求解目标 | 猜测说了什么词 | 文稿已知，只求每个词在音频中的位置 |
| 输出粒度 | 段级时间戳 | 词级 / 音素级时间戳 |
| 典型误差 | 段级可能漂移数百毫秒至数秒 | 干净语音约 ±20-50 ms（第三方口径，标注「待核实」） |
| 代表工具 | Whisper、faster-whisper、剪映 | WhisperX(wav2vec2)、MFA、Gentle、aeneas、stable-ts |
| 用于 | 从零生成文稿 | 已有准确文稿时升级时间轴、做逐字高亮 |

## 二、工具定位与选型表

| 工具 | 定位 | 强项 | 局限 | 最适用场景 |
| --- | --- | --- | --- | --- |
| Aegisub | 开源跨平台 ASS/SSA 特效编辑器（官网 aegisub.org，检索到 3.5.1 版，2026-10-17） | 关键帧、平滑移动、卡拉 OK、{\...} override tag、逐帧打轴 | 样式特效强但格式转换/批量处理弱；第三方评测曾称更新缓慢，与官网新版不一致，**状态「待核实」** | 番剧、特效字幕、卡拉 OK |
| Subtitle Edit | 免费开源「瑞士军刀」（nikse.dk/SubtitleEdit，MIT 许可） | 200+ 格式互转、OCR 硬字幕识别、Whisper 语音转文字、AI 翻译、批量时间轴平移、广播级 STL、波形打轴、活跃更新 | 需安装引擎/模型；ASS 特效编辑弱于 Aegisub | 专业交付、格式清洗、批量 QC |
| Arctime / ArcTime Pro | 国产跨平台可视化打轴（arctime.org） | 拖拽式时间轴、AI 转写、600+ 功能、可导 ASS/SRT、离线服务器方案 | 学习曲线陡；高精度转写需自配 API | 长视频、纪录片、课程字幕 |
| 剪映 / CapCut 专业版 | 一站式剪辑 + 自动字幕 | 中文自动识别快、与剪辑/花字一体、可导 SRT、模板生态 | 难逐帧精调、不支持 ASS 特效、超大批次稳定性一般、背景音乐大时错字上升 | 短视频、口播、快速出片 |
| OpenAI Whisper | 开源多语种 ASR 基座 | 多语种、翻译与语种识别单模型完成 | 原生无词级时间戳、段级会漂移、需代码基础 | 通用转写、批量长音频 |
| faster-whisper | Whisper 的 CTranslate2 重实现 | 同精度约 4 倍速度、显存更省、INT8 量化、word_timestamps、Silero VAD、本地离线 | GPU 需 cuBLAS/cuDNN；中文断句仍需人工 | 本地批量转写、隐私素材 |
| WhisperX | faster-whisper + wav2vec2 对齐 + pyannote 分离（BSD-2-Clause） | 精确词级时间戳、说话人标签、输出 SRT/VTT/TSV/JSON | 一次加载 3 个模型、需 HuggingFace token 并接受模型条款；数字/金额不对齐、重叠语音表现差 | 访谈、会议、需逐字对齐的字幕 |
| ffmpeg | 命令行媒体处理 | 格式互转、软字幕封装、硬烧、提取、编码转换 | 不做识别、不做文本编辑 | 流水线首尾两端 |

## 三、可执行规范与参数表

### 3.1 faster-whisper 关键参数（来自官方 README）

| 参数 | 取值 | 说明 |
| --- | --- | --- |
| model_size | `large-v3`、`turbo`、`small` 等 | 模型越大越准、越吃显存 |
| device / compute_type | `cuda`+`float16` / `cuda`+`int8_float16` / `cpu`+`int8` | GPU 用 FP16，CPU 用 INT8 |
| beam_size | 5 | 解码束宽 |
| word_timestamps | True | 打开词级时间戳 |
| vad_filter | True | 集成 Silero VAD，滤除无语音片段；默认只移除 > 2 秒静音 |
| vad_parameters | `dict(min_silence_duration_ms=500)` | 自定义静音阈值 |
| 批量推理 | `BatchedInferencePipeline`，`batch_size=16` | 长音频吞吐优化 |

**重要**：`model.transcribe()` 返回的 `segments` 是 **generator**，只有迭代（或 `list()`）时才真正开始转写，忘记 materialize 会以为「没输出」。

### 3.2 强制对齐工具对照

| 工具 | 对齐模型 | 备注 |
| --- | --- | --- |
| WhisperX | wav2vec2 音素模型 | 需语言对应的对齐模型；英/法/德/西/意等有默认模型 |
| Montreal Forced Aligner (MFA) | 音素对齐 | 经典，需语言音素模型，社区模型多 |
| Gentle / aeneas | 轻量对齐 | 适合已有文稿的粗对齐 |
| stable-ts | 改进 Whisper 词时间戳 | `result.to_srt_vtt(..., word_level=True)` |
| ctc-forced-aligner | CTC 解码 | 多语言 |

### 3.3 人工校对三级流程

| 级别 | 执行者 | 检查内容 |
| --- | --- | --- |
| 一级自检 | 剪辑/字幕员 | 错别字、标点、断行、的/地/得、数字单位 |
| 二级确认 | 客户方至少 2 人独立审阅 | 专业术语、人名、产品名、品牌译法 |
| 三级终审 | 团队另一人「纯看字幕不看画面」 | 最易发现遗漏与语义反转（尤其漏掉 not） |

### 3.4 时间轴批量平移与 ffmpeg 命令表

| 需求 | 做法 |
| --- | --- |
| 整体平移 | Subtitle Edit 的 Adjust all times；或本文 `shift.py`；改片后必须重跑 |
| 局部变速/帧率换算 | Subtitle Edit 的帧率转换；先确认源与目标帧率（23.976/24/25/30） |
| 格式互转 | `ffmpeg -i in.srt out.ass` / `out.vtt` |
| MP4 封装软字幕 | `-c:s mov_text` |
| MKV 封装软字幕 | `-c:s srt` / `-c:s ass` / `-c copy` |
| 硬烧 SRT | `-vf "subtitles=file.srt"` |
| 硬烧 ASS | `-vf "ass=file.ass"` |
| 老字幕编码 | `subtitles=x.srt:charenc=GBK` |
| 覆盖样式 | `force_style='FontName=Arial,FontSize=24,Outline=2'` |
| 选容器内字幕流 | `subtitles=input.mkv:si=0` |
| 提取字幕 | `ffmpeg -i input.mkv -map 0:s:0 out.srt` |

## 四、操作步骤与工作流（含本机 ffmpeg 8.1.2 实测通过的命令）

```bash
# ① 抽 16k 单声道音频（Whisper 系推荐输入）
ffmpeg -y -i input.mp4 -vn -ac 1 -ar 16000 audio.wav

# ② 安装转写引擎
pip install faster-whisper

# ⑦-a 软字幕封装：MP4 必须 mov_text
ffmpeg -y -i input.mp4 -i subs.srt \
  -map 0:v -map 0:a -map 1 -c:v copy -c:a copy -c:s mov_text \
  -metadata:s:s:0 language=chi -metadata:s:s:0 title="Chinese" output.mp4

# ⑦-b 软字幕封装：MKV 双语言 + 默认轨
ffmpeg -y -i input.mp4 -i zh.srt -i en.srt \
  -map 0:v -map 0:a -map 1 -map 2 -c copy -c:s srt \
  -metadata:s:s:0 language=chi -metadata:s:s:0 title="Chinese" \
  -metadata:s:s:1 language=eng -metadata:s:s:1 title="English" \
  -disposition:s:0 default output.mkv

# ⑦-c 硬烧（视频必须重编码）
ffmpeg -y -i input.mp4 -vf "subtitles=subs.srt" -c:v libx264 -c:a copy hard.mp4
ffmpeg -y -i input.mp4 -vf "ass=subs.ass" -c:v libx264 -c:a copy hard_ass.mp4

# ⑦-d 验收轨道
ffprobe -v error -select_streams s \
  -show_entries stream=index,codec_name:stream_tags=language,title -of json output.mkv
```

步骤 ② 的转写脚本 `asr_to_srt.py`（依赖 faster-whisper，其余为标准库）：

```python
from faster_whisper import WhisperModel

def ts(t):
    total = int(round(t * 1000))
    h, total = divmod(total, 3600000)
    m, total = divmod(total, 60000)
    s, ms = divmod(total, 1000)
    return "%02d:%02d:%02d,%03d" % (h, m, s, ms)

model = WhisperModel("large-v3", device="cuda", compute_type="float16")
segments, info = model.transcribe(
    "audio.wav", beam_size=5, word_timestamps=True, vad_filter=True,
    vad_parameters=dict(min_silence_duration_ms=500))
segments = list(segments)  # generator 必须 materialize 才会真正执行转写
with open("out.srt", "w", encoding="utf-8") as f:
    for i, seg in enumerate(segments, 1):
        f.write("%d\n%s --> %s\n%s\n\n" %
                (i, ts(seg.start), ts(seg.end), seg.text.strip()))
print("lang=%s p=%.2f cues=%d" %
      (info.language, info.language_probability, len(segments)))
```

时间轴批量平移 `shift.py`（`python shift.py subs.srt +1.5 shifted.srt`）：

```python
import re, sys
pat = re.compile(r"(\d{2}):(\d{2}):(\d{2}),(\d{3})")
def to_ms(m):
    h, mi, s, x = map(int, m.groups())
    return (h * 3600 + mi * 60 + s) * 1000 + x
def to_tc(v):
    v = max(0, v)
    h, v = divmod(v, 3600000)
    mi, v = divmod(v, 60000)
    s, x = divmod(v, 1000)
    return "%02d:%02d:%02d,%03d" % (h, mi, s, x)
shift = int(round(float(sys.argv[2]) * 1000))
src = open(sys.argv[1], encoding="utf-8-sig").read()
out = pat.sub(lambda m: to_tc(to_ms(m) + shift), src)
open(sys.argv[3], "w", encoding="utf-8").write(out)
```

质检脚本 `qc.py`（结构、重叠、时长、CPS、行数、空文本、单调性）：

```python
import re, sys
pat = re.compile(r"(\d{2}):(\d{2}):(\d{2}),(\d{3}) --> (\d{2}):(\d{2}):(\d{2}),(\d{3})")
def ms(a):
    h, mi, s, x = map(int, a)
    return (h * 3600 + mi * 60 + s) * 1000 + x
blocks = open(sys.argv[1], encoding="utf-8-sig").read().strip().split("\n\n")
prev_start, prev_end = -1, -1
for i, b in enumerate(blocks, 1):
    lines = [x for x in b.splitlines() if x != ""]
    m = pat.search(b)
    if not m or len(lines) < 3 or not lines[0].strip().isdigit():
        print("#%d STRUCT ERROR" % i)
        continue
    st, en = ms(m.group(1, 2, 3, 4)), ms(m.group(5, 6, 7, 8))
    text = re.sub(r"<[^>]+>|\{[^}]*\}", "", " ".join(lines[2:]))
    dur = (en - st) / 1000.0
    cps = len(text) / dur if dur > 0 else 999
    issues = []
    if en <= st: issues.append("non-positive duration")
    if st < prev_start: issues.append("out of order")
    if st < prev_end: issues.append("overlap %dms" % (prev_end - st))
    if dur < 0.833: issues.append("too short")
    if dur > 7.0: issues.append("too long")
    if cps > 20.0: issues.append("CPS %.1f" % cps)
    if len(lines) - 2 > 2: issues.append("over 2 lines")
    if not text.strip(): issues.append("empty text")
    if issues:
        print("#%d [%s] %s" % (i, "; ".join(issues), text[:36]))
    prev_start, prev_end = st, en
```

质检脚本思路可继续扩展：BOM 与编码探测、序号单调、CPS 按语言切换阈值（中文按字/秒）、行数与每行字数、相邻间隙 < 2 帧、跨镜头检测、专有名词表比对、语言标签与轨道数一致性、硬烧后抽帧 OCR 复核。

## 五、常见错误与排查

| 现象 | 根因 | 修复 |
| --- | --- | --- |
| 转写「没输出 / 结果为空」 | `segments` 是 generator 未迭代 | `segments = list(segments)` |
| 字幕整体前后漂移数秒 | Whisper 段级时间戳漂移 | 上 WhisperX / wav2vec2 强制对齐，或用 `shift.py` 整体平移后人工微调 |
| 词级时间戳仍不准（尤其中文/数字） | ASR 插值而非真对齐 | 换强制对齐工具；金额与数字人工复核 |
| 人名、品牌、数字错 | ASR 领域词缺失 | 建术语表 + 三级校对；可用 initial_prompt 提示（Whisper 系） |
| 背景音乐大时错字率飙升 | 语音被 BGM 掩盖 | 先做人声分离/降噪再转写，或换人工听写 |
| 改了剪辑后字幕全偏 | 未锁定最终版 | 改片后重跑对齐与整体平移 |
| GPU 跑不起来 | 缺 cuBLAS/cuDNN（Linux 需设 LD_LIBRARY_PATH） | 按 faster-whisper 官方 Requirements 安装，或退回 `device="cpu", compute_type="int8"` |
| WhisperX 分离失败 | 缺 HuggingFace token 或未接受 pyannote 模型条款 | 申请 token 并接受条款；重叠语音场景不依赖分离结果 |
| 硬烧后字幕没出现 | `-vf` 与 `-c copy` 同时用于视频 | 视频 `-c:v libx264` 重编码，音频可 `-c:a copy` |
| Windows 路径报错 | 盘符冒号被 filtergraph 当分隔符 | 写成 `subtitles='F\:/work/subs.srt'`，或改用相对路径 |
| ASS 字体走样 | 目标机缺字体 | `ass=subs.ass:fontsdir=/path/to/fonts`，并随片附授权合规字体 |
| SRT 第一条丢失 | 带 BOM | 用 `utf-8-sig` 读取、写回无 BOM 的 UTF-8 |
| MP4 里 title 不显示 | mov_text 对 title 支持有限（本机实测） | 改用 MKV 或只依赖 language 标签 |
| 字幕与画面差半秒 | 帧率/时间基不一致 | 确认 23.976/25/30，按帧率换算 |

## 六、速查清单

- [ ] 音频已抽成 16k 单声道 WAV，且剪辑版本已锁定
- [ ] 转写引擎参数明确：模型、device/compute_type、beam_size、word_timestamps、vad_filter
- [ ] 需要精确对齐时已启用强制对齐，而非只用 ASR 段级时间戳
- [ ] 断句在语义边界，CPS / 停留 / 2 帧间隙通过 qc.py
- [ ] 三级校对完成，专名、数字、否定词、术语表已核
- [ ] 时间轴平移有脚本可复现，改片后重跑
- [ ] 封装按容器选对：MP4→mov_text，MKV→srt/ass/copy
- [ ] 硬烧必重编码视频；字体已随片或指向 fontsdir
- [ ] 用 ffprobe 复核轨道 codec、language、title、default

# 多语言与无障碍字幕

> 分类：字幕系统 | 主题：翻译字幕 / CC / SDH、WCAG 2.2、多语言轨道与本地化 | 整理日期：2026-11-10 | 适用：无障碍交付、多语言发行、教育媒体与出海内容

## 一、核心原理与概念对比

字幕领域最常混淆的是三个术语，它们的**前提假设**不同，决定了内容清单完全不同：

| 类型 | 常见缩写 | 假设观众 | 必须包含 | 通常省略 |
| --- | --- | --- | --- | --- |
| 翻译字幕 Subtitles | SUB | 听得见，但不懂原语言 | 对白/旁白的译文 | 音效、说话人标识 |
| 隐藏式字幕 Closed Captions | CC | 听不见 | 对白 + 说话人标识 + 有意义的非语音声音 | — |
| 听障字幕 SDH | SDH | 听不见，且可能需要翻译 | CC 的全部信息 + 同语或译文对白 | — |

一句话记忆：**subtitles 假设观众能听、captions 假设观众不能听**；SDH（Subtitles for the Deaf and Hard of Hearing）把两者合并，既可以是同语（intralingual）也可以是跨语（interlingual）。W3C 把 captions 定义为「与媒体同步的、语音及理解媒体所需的非语音音频信息的文本替代」，因此**逐字稿 transcript 不等于 captions**，纯对白译文也不满足 captions。

| 呈现形态 | 定义 | 观众可控性 | 推荐场景 |
| --- | --- | --- | --- |
| Open captions（开放字幕） | 烧进画面像素 | 不可关闭、不可改字号 | 静音自动播放的社交短视频、转载后仍需保留 |
| Closed captions（闭合字幕） | 独立字幕轨 | 可开关、改大小、切语言 | 官网、学习平台、OTT、合规交付 |

W3C 把 open captions 列为满足 captions 要求的充分技术之一；但网站与教育平台通常优先 closed，因为观众可控制。两者并不存在「谁绝对更无障碍」，取决于发布位置。

### WCAG 2.2 相关成功标准（Guideline 1.2 Time-based Media）

| 编号 | 名称 | 级别 | 核心要求 |
| --- | --- | --- | --- |
| 1.2.1 | Audio-only and Video-only (Prerecorded) | A | 为纯音频/纯视频提供等价替代 |
| 1.2.2 | Captions (Prerecorded) | A | 为预录同步媒体的音频提供字幕 |
| 1.2.3 | Audio Description or Media Alternative (Prerecorded) | A | 提供媒体替代或音频描述 |
| 1.2.4 | Captions (Live) | AA | 为直播音频提供字幕 |
| 1.2.5 | Audio Description (Prerecorded) | AA | 为预录视频提供音频描述 |
| 1.2.6 | Sign Language (Prerecorded) | AAA | 手语翻译 |
| 1.2.7 | Extended Audio Description (Prerecorded) | AAA | 暂停画面以容纳描述的扩展音频描述 |
| 1.2.8 | Media Alternative (Prerecorded) | AAA | 完整文本替代 |
| 1.2.9 | Audio-only (Live) | AAA | 直播纯音频替代 |
| 1.4.3 | Contrast (Minimum) | AA | 文字 ≥ 4.5:1；大文字 ≥ 3:1 |
| 1.3.1 | Info and Relationships | A | 不能仅用颜色/形状/位置承载信息 |

实务结论：**预录带语音视频提供准确同步字幕 = Level A 基线**；音频描述在 AA；直播字幕为 AA。WCAG 规定「必须存在什么」，但不规定「怎么断行、怎么定时」，后者由 Netflix/BBC/DCMP 等风格指南补足。是否为法律义务取决于司法辖区、行业与合同，**标注「待核实」，需向客户合规负责人确认**。

## 二、可执行规范与参数表

### 2.1 CC / SDH 内容清单

| 元素 | 写法 | 规范要点 |
| --- | --- | --- |
| 说话人标识 | `MAYA:` / `[narrator]` / 姓名单独成行 | 画外或视觉不明显时必加；姓名单独成行与对白分开；不能仅靠颜色或位置（WCAG 1.3.1）；多人同说时分别置于各自下方，或分时间码显示 |
| 音效描述 | `[door slams]` / `[phone ringing]` | 方括号；DCMP 要求描述含音源（画面可见时可省）、小写、现在时、具体胜于笼统；画外音效用斜体；尽可能贴近声源 |
| 音乐 | `[tense music]`、歌词前后加 `♪` | 背景音乐描述客观、避免「优美」等主观词；歌词逐字；非必要背景音乐短于 5 秒不加字幕（DCMP 6.2.1.7） |
| 语气 / 语调 | `[whispering]`、`[sarcastic]`、`[laughing]` | 仅在改变理解时标注；持续声响用现在分词，突发声响用动词第三人称形式 |
| 外语 / 方言 | `[speaking French]` | DCMP 要求尽量标注原文，不擅自译成英语；保留方言特色；脏话俚语如实标注 |
| 静音 / 无音频 | `[no audio]` / `[silence]` | 画面显示人物交谈但无声音时标注 |

编辑判据只有一个：**这个声音会不会改变观众的理解**——不是把所有环境音记成流水账。W3C 也把「选哪些音效」称为 more art than science。

### 2.2 呈现速率与结构（DCMP Captioning Key 官方口径）

| 项目 | 参数 |
| --- | --- |
| 呈现速率 | 低年级 ≤ 130 wpm，中级 ≤ 140 wpm，高年级 ≤ 160 wpm |
| 计数方式 | 按**词**计数（不是字符）；说话人标识、音效、音乐描述一并计入 |
| 最短 / 最长停留 | 40 帧（1 秒 10 帧） / 6 秒（背景音乐符号除外） |
| 调速技巧 | 在音频出现前后各「借用」15 帧（约 0.5 秒）；或删冗余、缩短改写 |
| 必须逐字、忽略速率 | 引用人物原话、名人发言、诗歌与出版物引文、歌词 |
| 大小写 | 混合大小写；全大写仅用于尖叫/呼喊，不用于强调单词 |
| 行数 / 换行 | 最好 2 行，必要时 3-4 行；在自然停顿处断行，不拆修饰语、介词短语、人名+头衔、连词后、助动词 |
| 对齐与位置 | DCMP 建议多行字幕**左对齐**、置于底部两行且不遮挡姓名条/口型/关键图形，冲突时移到顶部 |

注意冲突：DCMP 倾向左对齐、Netflix 要求居中，**按交付对象择一，不可混用**；本项目「待核实」以最终平台指南为准。DCMP 三大字幕要素为同步性、等效性、可及性；五大质量为准确、一致、清晰、易读、平等。

### 2.3 多语言轨道命名与语言标签

| 语言 | BCP 47 | ISO 639-2（ffmpeg MP4 用） | 说明 |
| --- | --- | --- | --- |
| 英语 | en | eng | |
| 法语 | fr | fra（另有书目码 fre） | |
| 德语 | de | deu（另有 ger） | |
| 西班牙语 | es | spa | |
| 越南语 | vi | vie | 两位码在 MP4 中不可靠 |
| 日语 | ja | jpn | |
| 韩语 | ko | kor | |
| 中文简体 / 繁体 | zh-Hans / zh-Hant | zho | zho 无法区分简繁，须靠 BCP 47 子标签 |
| 未定 / 多语 / 无语言内容 | und / mul / zxx | und / mul / zxx | 特殊码 |

规则：ffmpeg 的 `-metadata:s:s:N language=` 使用 ISO 639-2 三位码；MKV 同时存 legacy Language（ISO 639-2）与 LanguageIETF（BCP 47），可写 `zh-Hans`；MP4 用三位码更可靠。**该结论来自第三方整理，标注「待核实」**，且本机实测发现 MP4/mov_text 下 `title` 标签未写入，MKV 下正常。轨道命名建议把类型写进 title，例如 `title="Chinese (Simplified, SDH)"`、`title="English (CC)"`，便于播放器与审片区分；SDH/CC 轨应与普通翻译字幕分轨，不要合并。

### 2.4 翻译字数压缩与文化适配

| 问题 | 处理 |
| --- | --- |
| 长度伸缩 | 英中互译长度不成比例，译文必须「浓缩改写」而非逐字忠实；必要时重排两行 |
| 上下文割裂 | 整批送译或拼接相邻条目，避免逐条翻译导致代词指代、时态、术语不一致 |
| 术语一致性 | 建立术语表，强制统一人名、品牌、专有名词 |
| 口语与语气词 | 送译文本可清理口头禅，但屏幕文本是否清理需另行决定（尤其 SDH 需保留 hesitate 等） |
| 文化负载词 | 成语、俚语、网络流行语标记为人工复核项 |
| 数字 / 单位 / 币种 | 统一「万」与「10k」、日期、货币格式；Netflix 规定币种保持原币种不换算 |
| 双语排布 | 源语言在上、目标语言在下共 2 行；中文约 14-16 字、英文 ≤ 8 词，避免头重脚轻 |
| 片中字幕 | 路牌、屏幕文字等强制叙事单独成条/单独轨，不与对白混合 |

字幕翻译天然带压缩属性；DCMP 的编辑原则是**保留原意、内容与基本词汇**，允许删冗余但不允许把生僻词换成简单同义词。

## 三、操作步骤与工作流（含可运行命令）

七步流程：**① 锁定最终剪辑**（改片会推翻上百条时间轴）→ ② 生成定时草稿 → ③ 人工改字词（专名、数字、否定词，一个漏掉的 not 会反转语义）→ ④ 补有意义的非语音声音 → ⑤ 补说话人标识 → ⑥ 可读时间轴与断行 → ⑦ 选 open/closed 并导出，必要时另附 transcript 与音频描述脚本。

SDH 版 SRT 片段示例（英文，ASCII 标点）：

```srt
1
00:00:01,000 --> 00:00:03,200
[door slams]

2
00:00:03,400 --> 00:00:06,000
MAYA: I did not say that.

3
00:00:06,200 --> 00:00:09,000
[tense music]
[narrator] She was already gone.
```

多语言 + SDH 分轨封装（本机 ffmpeg 8.1.2 实测通过）：

```bash
# 1. 三条字幕轨：简体中文翻译、繁体中文、英文 SDH
ffmpeg -y -i input.mp4 -i zh-Hans.srt -i zh-Hant.srt -i en-sdh.srt \
  -map 0:v -map 0:a -map 1 -map 2 -map 3 -c copy -c:s srt \
  -metadata:s:s:0 language=chi -metadata:s:s:0 title="Chinese (Simplified)" \
  -metadata:s:s:1 language=chi -metadata:s:s:1 title="Chinese (Traditional)" \
  -metadata:s:s:2 language=eng -metadata:s:s:2 title="English (SDH)" \
  -disposition:s:0 default output.mkv

# 2. 逐轨验收
ffprobe -v error -select_streams s \
  -show_entries stream=index,codec_name:stream_tags=language,title -of json output.mkv

# 3. 网页用 WebVTT：带 cue identifier 与定位，便于 ::cue 定制字号
ffmpeg -y -i en-sdh.srt en-sdh.vtt
```

生成的 WebVTT 可用 `::cue` 提高对比度与字号（配合 WCAG 1.4.3）：

```css
::cue { color: white; background-color: rgba(0,0,0,0.75); font-size: 1.2em; }
```

## 四、常见错误与排查

| 现象 | 根因 | 修复 |
| --- | --- | --- |
| 交付被判不满足无障碍 | 用纯翻译字幕当 CC 交 | 补说话人标识、音效、音乐描述，或单独出 SDH 轨 |
| 只靠颜色区分说话人 | 违反 WCAG 1.3.1 | 用姓名标签/`[narrator]`，颜色只作辅助 |
| 音效写成 `[loud noise]` | 缺音源、太笼统 | 改成 `[door slams]`，具体、小写、现在时 |
| 自动字幕未校对直接发布 | 名字/数字/否定词错 | 人工通读，尤其 `not`、专名、金额 |
| 漏掉「not」导致语义反转 | ASR 误识 | 三级校对，终审者纯看字幕不看画面 |
| 直播按 A 级要求准备 | 直播是 1.2.4 AA | 用专业实时字幕员，录播后再轻校一次 |
| 简繁都被标成 zho | ISO 639-2 无法区分 | MKV 用 BCP 47 `zh-Hans` / `zh-Hant` |
| 播放器跳过某语言轨 | 用了两位语言码或 `und` | 改用 ISO 639-2 三位码 |
| 硬烧字幕当唯一无障碍方案 | 观众无法改字号/关闭 | 官网/教育平台优先 closed 轨，社交版再另出 open 版 |
| 全程记环境音 | 把音效当事件日志 | 只保留改变理解的声音 |
| 歌词与背景音乐混排 | 未用音乐图标与逐字规则 | 歌词逐字 + 首尾 `♪`，短背景音乐省略 |
| 改了剪辑后字幕全偏 | 未锁定最终版 | 任何改片后重跑时间轴对齐 |

## 五、速查清单

- [ ] 已明确交付物是 SUB / CC / SDH 中的哪一类，并写入文件名与轨道 title
- [ ] 预录带语音视频满足 1.2.2（A）；直播按 1.2.4（AA）；音频描述按 1.2.5（AA）
- [ ] 说话人标识不依赖颜色/位置；画外音、情绪、外语均已标注
- [ ] 音效描述有音源、小写、现在时、方括号；歌词带 ♪；背景音乐 < 5 秒省略
- [ ] 按 DCMP 词数口径核速率：130/140/160 wpm，40 帧 - 6 秒，标识与音效计入
- [ ] 引文、名人发言、诗歌、歌词逐字，不受速率限制
- [ ] 多语言轨道用 ISO 639-2 三位码；简繁用 BCP 47 子标签；default 只设一条
- [ ] SDH 与翻译字幕分轨；片中字幕独立成条
- [ ] 译文已做压缩、术语统一与文化负载词人工复核
- [ ] 文字对比度 ≥ 4.5:1（大文字 ≥ 3:1），并保留 closed 版本
- [ ] 所有「待核实」的合规义务与平台细则已向官方/客户复核

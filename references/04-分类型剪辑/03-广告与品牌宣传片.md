# 广告与品牌宣传片剪辑手册

> 分类：分类型剪辑 | 主题：信息流广告 / 品牌 TVC / 宣传片 / 多版本套剪 | 整理日期：2026-11-10 | 适用：品牌方、广告后期、投放优化师、电商素材团队

> **数值声明**：所有投放位画幅、分辨率、时长、文件大小、文案字数、封面尺寸一律「以平台最新官方文档为准」，投放前须在后台复核；冲突或经验值标注「待核实」。
>
> **合规声明**：本文仅为合规**提示**，禁用词与法规完整口径「另见 05-版权法规 分类」，正式投放须经法务复审。

## 一、类型目标与评价指标

**目标**：在极短且常被跳过/静音的环境里完成「注意 → 认知 → 偏好 → 行动」。宣传片偏形象与回想，效果广告偏点击与转化，二者对信息密度的取舍相反。

| 指标 | 含义 | 关联剪辑决策 |
|---|---|---|
| 前 5 秒留存 / 2 秒注意力 | 跳过按钮出现前是否被看见 | 品牌与钩子必须前置 |
| 品牌回想率 | 看完能否说出品牌 | 全程角标 + 首尾 end card |
| 信息层级达成度 | 单一核心主张是否被记住 | 1 条片只讲 1 个主张 |
| 完播率 / 观看时长 | 完整观看占比 | 节奏与音乐 |
| 点击率 CTR | 点击 / 曝光 | CTA、首帧、字幕 |
| CVR / CPA / ROAS | 转化成本与回报 | 落地页一致性、CTA 强度 |
| A/B 胜出率 | 对照实验结论 | 单变量版本矩阵 |

> 核心约束：**时长越短，信息层级越要砍到只剩一条**。6 秒 bumper 只容得下"一个主张 + 一次品牌露出"，硬塞 30 秒 TVC 全部内容是最常见的失败。

## 三、结构模板（30s / 15s / 6s 套剪时间轴）

**同一母版一次拍剪、派生三版**，按「主张 → 证据 → 品牌 → 行动」逐层削减：

| 时间轴 | 30 秒主版 | 15 秒剪版 | 6 秒 Bumper |
|---|---|---|---|
| 0–2s | 强钩子 + 品牌前置 | 钩子 + 品牌同框 | 单一产品镜头 + 品牌名 |
| 2–5s | 痛点 / 利益点直给 | 单一卖点 | 一句 tagline |
| 5–12s | 演示第 1 点 + 证据 | 演示 / 证据压缩为 1 组 | Logo + 一句行动 / 网址 |
| 12–20s | 演示第 2–3 点 | CTA 前置 | — |
| 20–26s | 信任状 / 促销 / 数据引证 | Logo + end card | — |
| 26–30s | CTA + Logo end card ≥2–3 秒 | — | — |

**信息层级与品牌露出时长**（建议值，待核实）：

| 层级 | 30s | 15s | 6s |
|---|---|---|---|
| 单一核心主张 | 1 条，重复 ≤3 次 | 1 条 | 1 条 |
| 支撑证据 / 演示 | 2–3 个 | 1 个 | 0 |
| CTA | 结尾 3–4 秒 + 口播 | 结尾 2–3 秒 | 结尾 1–2 秒 |
| 品牌露出 | 全程角标 + 首尾 ≥3 秒 | 角标 + end card ≥2 秒 | 全程或结尾 ≥2 秒 |

> CTA 三件套：口播 CTA（建议 10 秒内出现一次）+ 屏幕按钮/文字 + 落地页一致。竖版主视觉限中央净区，Logo 放上/左安全区，避开底部描述与购买按钮（见 01 分类）。

**A/B 版本矩阵**（每版只改 1 个变量）：

```
变量1 钩子: "悬念型" vs "利益型" vs "冲突型"
变量2 首帧: "产品特写" vs "人物表情" vs "结果对比"
变量3 CTA: "立即购买" vs "了解更多" vs "限时领取"
变量4 音乐: "卡点强节奏" vs "情绪铺底"
变量5 时长: 30s vs 15s vs 6s
```

## 四、关键剪辑技法与具体参数

| 项目 | 30 秒主版 | 15 秒 | 6 秒 Bumper |
|---|---|---|---|
| 平均单镜时长 | 1.5–3 秒 | 1–2 秒 | 1–2 个镜头走完全片 |
| 前 5 秒切换密度 | 每 1–2 秒 1 切 | 每 1 秒 1 切 | 单次或双次切 |
| 镜头总数参考 | 10–18 个 | 6–10 个 | 1–3 个 |
| 字幕 | 单屏 ≤12 字，卖点/价格/CTA 花字放大 | ≤10 字 | ≤8 字 |
| 音乐 | 锁定最终版再剪，切点吸附 BPM 强拍 | 副歌前置 | 一记重拍 / 音效 |
| 响度 | 约 −14 LUFS、−1 dBTP（待核实），人声处 ducking | 同左 | 同左 |

**套剪工程做法**：先完成 30 秒横版母版（留存 ProRes/H.264 母版）→ 派生 15 秒（删证据层、CTA 前移）→ 派生 6 秒（只留最强视觉 + 一句文案 + Logo）→ 最后做 9:16 竖版与 Shorts 版（重新构图、主体居中）。**不要为每版从零重剪，也不要把横版直接塞进竖版**（16:9 裁 9:16 会丢约 68% 宽度）。

**品牌露出**：全程角标 + 首尾 end card（≥2–3 秒，含 Logo、Slogan、网址/二维码）；可跳过广告必须在第 5 秒跳过按钮出现前完成至少一次清晰品牌露出。

## 五、音频与字幕的特殊处理

1. **"必须有声"与"静音可读"双满足**：视频号广告官方明确要求视频「必须有声音」；但信息流常静音自动播放，价格、卖点、CTA 必须靠字幕与画面独立成立。检验法：静音看一遍能否看懂主张与行动。
2. **提示语 / 免责条款**（合规重点）：不得用极小字体、浅色、模糊水印、折叠隐藏、快速闪过规避展示；字号须与主文案成合理比例、颜色与背景色差明显、停留时长充足，杜绝"大字吸睛、小字免责"。
3. **广告标识**：短视频、图文、直播等互联网推广内容需依法清晰标注「广告」字样（提示，详见 05 分类）。
4. **引证内容**：数据、统计、调查结果、引用语须真实准确并标明出处；有适用范围与有效期限的须明确表示；禁用虚构或无法验证的统计资料。
5. **音乐与字体**：商业投放须用有明确商业授权的音乐、字体、图片、肖像并留凭证；平台内置音乐通常只授权平台内使用，不自动覆盖广告投放、官网或跨平台（见 05 分类）。

## 六、常见坑与反面案例（合规红线仅提示）

| 坑 | 反面案例 | 后果 | 修正 |
|---|---|---|---|
| 照搬长片到短版 | 30 秒 TVC 压成 6 秒 | 信息过载、一个都没记住 | 只留 1 主张 + 1 品牌 + 1 行动 |
| 品牌露太晚 | 结尾才出 Logo | 5 秒跳过前未被看见 | 前 2 秒前置 + 全程角标 |
| 多主张并列 | 一条片讲 3 个卖点 + 2 个促销 | 回想率归零 | 信息层级砍到三层内 |
| 小字免责 | 8px 浅灰字一闪而过 | 误导性大小字，违规 | 字号成比例、停留充足 |
| 未标"广告" | 原生种草实为付费推广 | 违规 | 清晰标注广告字样 |
| **绝对化用语** | "最 / 第一 / 唯一 / 国家级 / 顶级 / 100%" | 违反《广告法》第九条，处罚口径 20 万–100 万元（待核实） | 改客观描述 + 可核查依据 |
| 无时限限时语 / 诱导语 | "随时结束""最后一波""点击有惊喜""秒杀""抢爆" | 违规 | 标具体活动日期 / 真实利益表述 |
| 权威性背书 | "国家机关推荐""特供""专供""质量免检" | 违规 | 删除，勿借官方名义 |
| 落地页不一致 | 竖版切片挂非同款链接 | 虚假宣传 / 不正当竞争 | 商品与口播完全一致 |
| A/B 多变量齐改 | 一次换钩子 + 音乐 + CTA | 无法归因 | 每版单变量 |
| 横版硬裁竖版 | 主体被切、文字出框 | 素材报废 | 重新构图或模糊填充 |

> 上表禁用词仅为**高频风险提示**，不构成完整清单；完整口径、例外与最新修订「另见 05-版权法规 分类」，投放前须过合规审。

## 七、交付前检查清单

- [ ] 30s / 15s / 6s 由同一母版派生，信息层级逐层削减
- [ ] 6 秒版只含 1 主张 + 1 品牌露出 + 1 行动
- [ ] 可跳过广告第 5 秒前已有清晰品牌；角标 + end card ≥2–3 秒
- [ ] 画幅/分辨率/时长/文件大小/封面符合投放位（以平台最新官方文档为准复核）
- [ ] 视频有声音，且静音下主张/价格/CTA 仍可读
- [ ] CTA 三件套齐全，10 秒内有一次口播 CTA
- [ ] 提示语字号、色差、停留合规，无小字隐形/快速闪过
- [ ] 已清晰标注「广告」；引证数据标明出处、范围、有效期
- [ ] 全文案过禁用词检查（绝对化、时限、诱导、权威背书、虚假夸大）——完整见 05 分类
- [ ] 音乐、字体、图片、肖像、档案有商业授权凭证
- [ ] 整体约 −14 LUFS、−1 dBTP（以平台最新官方文档为准复核）
- [ ] 竖版主体居中，避开底部描述与右侧按钮安全区
- [ ] A/B 每版仅改 1 个变量，命名与投放记录可追溯
- [ ] 法务 / 合规复审通过并留档

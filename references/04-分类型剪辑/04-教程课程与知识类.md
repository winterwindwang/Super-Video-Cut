# 教程、课程与知识类视频剪辑手册

> 分类：分类型剪辑 | 主题：屏幕录制教程 / 在线课程 / 软件演示 / 代码与公式教学 | 整理日期：2026-11-10 | 适用：课程设计师、技术讲师、教育视频后期、企业培训与 LMS 交付团队

> **数值声明**：录制分辨率、帧率、码率、字体像素、字号、时长、字幕行数与停留秒数、响度一律「以平台最新官方文档 / 所用工具与 WCAG 最新标准为准」，交付前须在目标设备实测；经验值与研究统计标注「待核实」。

---

## 一、类型目标与评价指标

**目标**：让学习者"看得懂、跟得上、做得出、查得到"。与短视频"抢注意力"相反，知识类要**降低认知负荷、把节奏控制权交还学习者**——播放/暂停/回放/倍速/跳转比任何钩子都重要。

| 指标 | 含义 | 验收方式 |
|---|---|---|
| 知识点达成率 | 学完能否完成目标操作 | 随堂测验 / 实操任务正确率 |
| 分段完播率 | 每个 5–7 分钟分段完成度 | 后台分段曲线 |
| 回放 / 暂停热区 | 哪些时间点被反复回看 | 定位"没讲清"段落并补信号 |
| 信息留存 | 延迟测验表现 | 段末问题 + 小结 |
| 可访问性合规 | WCAG 2.1/2.2 AA 达标 | 字幕、transcript、音频描述、键盘操作逐项审 |

> 教学设计原则：**片段短小 + 需要时给提示（signaling）+ 声音清晰**。删掉一切没有教学意义的画面、音乐与动效；精确命令、代码、路径、设置值必须以可访问文本给出，让学习者无需反复回放即可扫描、复制、比对。

## 二、平台规格与录制参数（以平台最新官方文档为准）

| 项目 | 推荐值 | 理由 |
|---|---|---|
| 录制分辨率 | 3840×2160（4K） | 为 2× Zoom 留画质余量；1920×1080 直录无放大余量 |
| 交付分辨率 | 1920×1080（16:9）；竖屏切片 1080×1920（9:16） | 一份母版派生多平台 |
| 帧率（静态代码 / 终端） | 30fps | 文本更新无需 60fps，文件更小 |
| 帧率（UI 交互 / 滚动 / 动画） | 60fps | 滚动与光标移动更顺滑 |
| IDE 字体 | ≥18–22px（1080p 可读），缩放 150%–175% | 太小是教学视频头号硬伤 |
| 编辑器设置 | 深色主题、行号 ON、minimap OFF、侧栏收起 | 减少视觉噪声 |
| 音频 | 44.1–48kHz，外接麦 + 系统音**分轨** | 便于分别降噪与混音 |
| 导出编码 | H.264 + MP4（H.265 可选），1080p 4–8 Mbps | 兼容性优先 |
| 单段时长 | 每个聚焦步骤 30–90 秒 | 便于分段与检索 |
| 章节 / 分段 | 5–7 分钟；建议 ≤6 分钟 | Guo 等 2014 对 690 万次观看会话研究：中位参与度约 6 分钟达峰（衡量观看时长而非学习效果，待核实） |
| 背景音乐 | −18 ~ −24 dB，讲解时 ducking | 音乐不得争夺注意力 |

**平台落点**：B 站 / YouTube / 企业 LMS 以 16:9 1920×1080 为主；Udemy、Coursera、内部平台按各自上传规范（以平台最新官方文档为准）；派生知识点切片可转 9:16 1080×1920（安全区见 01 分类）。

## 三、结构模板（时间轴表）

**模板 A：6 分钟单节课**

| 时间轴 | 段落 | 任务 | 呈现 |
|---|---|---|---|
| 0:00–0:15 | 目标先行 | 用动词写目标："学完你会配置 X" | 标题卡 + 口播，不放片头动画 |
| 0:15–0:45 | 部件命名 + 信号 | 先说明各部分名称、给视觉信号 | 全景 1.0×，箭头/标签指向目标 |
| 0:45–4:30 | 3–5 个步骤 | 每步 30–90 秒，一步一子目标 | 讲解 → Zoom 演示 → 回全景复述 |
| 4:30–5:30 | 综合演示 / 常见错误 | 完整跑一遍，点出易错点 | 1.0×，错误处放大高亮 |
| 5:30–6:00 | 小结 + 一个问题 | 设停止点、预告下一节 | 关键点字幕卡 + 可复制命令清单 |

**模板 B：60–90 秒知识点切片**

| 时间轴 | 段落 | 要点 |
|---|---|---|
| 0:00–0:05 | 问题 / 结果预览 | 先给"学完能做到什么" |
| 0:05–0:15 | 部件命名 | 给术语与位置 |
| 0:15–1:10 | 操作演示 | 含 1–2 次 Zoom，关键帧停留 3–7 秒 |
| 1:10–1:30 | 复述 + 可复制文本 | 命令/公式文本卡给出 |

**章节与切片规划表**（可直接套用）：

| 章 | 知识点 | 时长 | 切片时间码 | 配套文本 |
|---|---|---|---|---|
| 1 | 环境准备 | 5:30 | 00:00 / 02:10 | 依赖清单、版本号 |
| 2 | 核心概念 | 6:00 | 00:00 / 03:20 | 术语表、示意图 |
| 3 | 分步实操 | 6:00 | 00:00 / 01:45 / 04:10 | 完整代码 / 命令 |
| 4 | 排错与验证 | 5:00 | 00:00 / 02:30 | 报错对照表 |

> 切片原则：在**有意义的子目标边界**切分，用章节标记或独立片段，不机械按固定时长切；每章边界设一个问题或停止点。

**录屏参数模板**（代码块内为 ASCII 直引号）：

```
resolution_record: "3840x2160"
resolution_deliver: "1920x1080"
fps_static_code: 30
fps_ui_scroll: 60
ide_font_px: 20
cursor_size: "1.5-2x"
zoom_code_focus: "1.5-2.0x"
zoom_transition_sec: 0.8
dead_air_remove_over_sec: 1.5
bgm_db: "-18 to -24"
```

## 四、关键剪辑技法与具体参数

| 技法 | 参数 | 操作要点 |
|---|---|---|
| 鼠标高亮 | 1.5–2×；黄/白圆环约 50px 半径；点击涟漪；平滑 0.9 | 点击前在目标停 0.5 秒；**不要绕圈圈光标**；讲代码时可隐藏 |
| 局部放大 Zoom | 代码 1.5–2.0×；UI 元素 2.0–2.5×；终端 1.5×；回全景 1.0× | 0.8s ease-in-out（终端/回全景 0.6s）；**先口播预告**"我们看这个函数"再放大 |
| Pan 平移 | 跟随活动区域，缓入缓出 | 下一次 pan 前至少保持 3 秒，不瞬跳 |
| 速度变速 | 导航 1.5×、重复操作 2×、关键时刻 1.0× | 删除 >1.5 秒停顿 |
| 分屏 / 画中画 | 教师头像 PiP（圆形/圆角带描边）；录屏 + 摄像头双轨 | 讲概念时出镜，操作演示时缩小或移出主体区 |
| 代码呈现 | 等宽字体、语法高亮、行号、逐行高亮、关键行放大 | 一次一焦点；**精确命令/路径/设置值须以可复制文本给出** |
| 公式 / 图表 | 大字号独立卡片、逐项高亮、与口播同步 | 停留 ≥3–7 秒，避免一闪而过 |
| 信息密度 | 一屏一焦点；信号"看右上角面板""注意光标这里" | 标签贴近被解释对象；删装饰性动效与转场 |
| 字幕停留 | 3–7 秒 / 屏，≤3 行，每行 ≤32 字符 | 底部居中，不遮挡关键 UI |

> 信号（signaling）能显著降低字幕与画面间的注意力分散：口播明确说"看哪里"比单纯加高亮更有效。镜头顺序固定为「全景交代 → Zoom 聚焦 → 回全景确认」，学习者才不丢空间感。

## 五、音频与字幕 / 可访问性要点

1. **音频分层**：外接麦录讲解、系统音单独一轨；整体响度约 −14 ~ −16 LUFS、−1 dBTP（待核实，以平台最新官方文档为准）；BGM −18 ~ −24 dB 并在人声处 ducking；全程音量一致，避免重叠人声或被音乐盖住。
2. **字幕（WCAG 2.1 AA）**：提供**闭字幕（可开关）**而非烧录硬字幕；覆盖全部语音与重要非语音声音（方括号标注 `[音乐]` `[笑声]`）；标识说话人；与音频同步；每行 ≤32 字符、≤3 行、停留 3–7 秒；对比度 ≥4.5:1，白字配纯/半透黑底，无衬线 ≥16pt（Arial/Helvetica/Verdana）；准确度 99%，不改写不意译。**不要只依赖自动生成字幕**，须人工校对专有名词。
3. **WCAG 2.2 关键标准**（以 WCAG 最新标准为准）：

| 标准 | 级别 | 要求 |
|---|---|---|
| 1.2.1 纯音频/纯视频 | A | 提供等价替代或音轨 |
| 1.2.2 字幕（预录） | A | 所有带音频预录视频须有同步字幕 |
| 1.2.3 音频描述或替代 | A | 重要视觉信息有等价说明 |
| 1.2.5 音频描述 | AA | transcript 不能替代 AA 要求 |
| 2.2.2 暂停/停止/隐藏 | A | 自动移动内容 >5 秒须可暂停 |

4. **完整 transcript**：含对白、说话人、重要声音与画面描述，置于播放器附近。transcript 便于扫描检索，但**不能替代同步字幕**，也不替代 1.2.5 的音频描述。
5. **学习者控制**：播放/暂停/seek/回放/音量可用，支持时提供倍速；自动播放内容须可暂停；播放器控件可键盘操作、有可读名称与状态、焦点顺序合理。
6. **不依赖单一通道**：不只用颜色、声音或运动传达必要区别；尊重 `prefers-reduced-motion`；避免有害闪烁。

## 六、常见坑与反面案例

| 坑 | 反面案例 | 后果 | 修正 |
|---|---|---|---|
| 录制=交付分辨率 | 1080p 录还做 2× Zoom | 放大后糊成一片 | 4K 录、1080p 交付 |
| 字体过小 | 14px IDE、侧栏全开 | 手机端读不清 | ≥18–22px，收起无关面板 |
| 只用硬字幕 / 只信自动字幕 | 烧录字幕 + 未校对 ASR | 不可访问、专名错 | 闭字幕 + 人工校对 99% |
| 光标乱飞 | 鼠标到处画圈 | 分散注意力 | 有目的移动、点击前停 0.5 秒 |
| Zoom 无预告 / 瞬跳 | 突然放大无过渡 | 丢失空间感 | 先口播预告 + 0.8s 过渡 |
| 命令只在画面里 | 一串命令一闪而过 | 无法复制、反复回放 | 配套可复制文本卡 |
| 一讲 20 分钟不分段 | 单文件长课无章节 | 负荷高、无法检索 | 5–7 分钟分段 + 章节标记 |
| 装饰动效与 BGM 盖讲解 | 满屏转场 + 音乐比人声响 | 干扰、信息丢失 | 删装饰；人声为锚，−18~−24 dB + ducking |
| 关键帧停留不足 | 公式/报错 <2 秒 | 看不清 | 停留 3–7 秒 |

## 七、交付前检查清单

- [ ] 4K 录制 / 1080p 交付，Zoom 后代码清晰；帧率按内容选 30 / 60fps
- [ ] IDE 字体 ≥18–22px、深色主题、行号开、minimap 与侧栏关
- [ ] 外接麦 + 系统音分轨；噪声处理、音量一致、BGM 未盖人声
- [ ] 光标 1.5–2× 高亮、无绕圈；Zoom 有预告 + 0.8s 过渡，pan 前停留 ≥3 秒
- [ ] 删净 >1.5 秒停顿，导航/重复已变速，关键时刻 1.0×
- [ ] 精确命令、代码、路径、公式均有**可复制文本**（画面 + 文档一致）
- [ ] 按子目标边界切 5–7 分钟分段并设章节标记，段末有问题
- [ ] 闭字幕可开关、同步、≤32 字符、≤3 行、3–7 秒、对比度 ≥4.5:1、≥16pt、人工校对 99%
- [ ] 完整 transcript 已提供；必要处有音频描述 / 视觉信息说明
- [ ] 播放器可播放/暂停/seek/回放/音量/倍速，键盘可操作，自动移动内容可暂停
- [ ] 未仅用颜色/声音/运动传达必要信息；尊重 reduced-motion、无有害闪烁
- [ ] 导出 H.264 + MP4、1080p 4–8 Mbps，响度按平台目标（以平台最新官方文档为准复核）

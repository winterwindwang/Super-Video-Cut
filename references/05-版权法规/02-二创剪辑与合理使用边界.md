# 二创剪辑与合理使用边界

> ⚠️ 本文件为创作参考资料，不构成法律意见；法规与司法口径会变化，商用/高风险项目请咨询专业律师并以最新官方文本为准。

> 分类：版权法规 | 主题：切条/搬运/混剪/解说/盘点/Reaction 的侵权风险分级、适当引用判断要素与合规决策树 | 整理日期：2026-11-10 | 适用：二创类短视频立项评估与发布前审查

## 一、核心规则（逐条）

**1. "二创"非法定免责类型。**《著作权法》无此概念，须拆成受控行为：截取＝第十条（五）复制权；重排改剧情＝（十四）改编权/（十六）汇编权；歪曲原意＝（四）保护作品完整权；上传＝（十二）信息网络传播权；用二创素材再剪＝第十三、十六条双重授权。第十三条明定演绎作品"行使著作权时**不得侵犯原作品的著作权**"——"加了字幕、配了音"不能自动免授权。

**2. 第二十四条第（二）项与总括句。**"为介绍、评论某一作品或者说明某一问题，在作品中**适当引用**他人已经发表的作品"，可不许可、不付酬，但总括句要求"**应当指明作者姓名或者名称、作品名称，并且不得影响该作品的正常使用，也不得不合理地损害著作权人的合法权益**"。三项义务缺一不可：指明义务（《实施条例》第十九条）、不影响正常使用、不不合理损害。第二款：该限制"适用于对与著作权有关的权利的限制"。

**3. 三步检验法。**《实施条例》第二十一条："使用可以不经著作权人许可的已经发表的作品的，**不得影响该作品的正常使用，也不得不合理地损害著作权人的合法利益**。"即"先落入具体情形、再独立通过三步检验"两道门槛。

**4. 北京市高级人民法院《侵害著作权案件审理指南》**（beijing.gov.cn，地方法院审理指引，非司法解释）：
- **7.10**："被告未经许可**通过信息网络向他人提供作品**，其提出属于'为个人学习、研究或者欣赏使用他人已发表作品'的合理使用抗辩，**不予支持**。"→ 上传公开平台，个人欣赏抗辩基本失效。
- **7.11 适当引用四因素**："（1）被引用的作品是否已经发表；（2）引用目的是否为介绍、评论作品或者说明问题；（3）被引用的内容在被诉侵权作品中所占的比例是否适当；（4）引用行为是否影响被引用作品的正常使用或者损害其权利人的合法利益"。
- **7.12**："未经许可以营利为目的，在面向社会公众开展的教育培训中翻译或者复制他人已发表作品的……不予支持。"另参照 7.1 抗辩事由、7.3 有限表达、7.4 必要场景、7.6 公有领域、7.9 合法授权。

**5. 国家版权局口径**（ncac.gov.cn，2021 网络版权保护与发展大会，刘文杰教授）："**仅仅将一部影视剧切分成几分钟的短视频，而不添加任何内容，此类化整为零的'搬运'谈不上构成二次创作，基本上属于法律所不允许的版权侵权行为**"；"**对影视剧加以剪辑，以达到观众在短时间内欣赏原作或其片断的效果，此类二次创作通常也要取得原作权利人的许可**"。同时承认评论、批评、讽刺性引用（如"盘点影视剧中的穿帮镜头"）及为介绍、说明问题、新闻报道、教育目的的合理使用有空间，但"这种介绍不能是单纯的大量复制或原著缩写"；结论"不能仅仅因为视频中存在着剪辑就断定侵权的存在"。

**6.「剑网 2023」执法重点**（ncac.gov.cn，2023-10-23）："重点整治**未经授权以短视频形式对视听作品删减切条、改编合辑并通过网络传播的侵权行为**"；平台侧整治"以用户上传为由**滥用'避风港'规则、以合理使用为由传播侵权作品、以自设程序为由拖延履行通知—删除义务**"。

**7. 北京市知识产权局《著作权典型问题（数字经济）》**：切条可能侵犯**署名权、复制权、修改权、保护作品完整权、信息网络传播权**；"**引用比例并不必然构成合理使用免责**"；"实质呈现了视听作品的主要画面、主要情节等内容的行为，超出了介绍、评论的必要限度，在客观上起到了**替代原作品效果**的，不构成合理使用"。

**8. 公开典型案例**（案号与细节来自律所/媒体转述，见「待核实」）：
- **"图解电影"案**（优酷诉深圳蜀黍科技；一审 (2019)京0491民初663号，二审 **(2020)京73民终187号** 北京知识产权法院）：截取剧集 **382 幅画面**制图片集配文字，主张仅用原片 **0.5%**、属推介与适当引用。裁判要旨："**合理引用的判断标准并非仅取决于引用比例，而应取决于介绍、评论或者说明的合理需要**"；图集"涵盖了涉案剧集的主要剧情和关键画面"，造成实质性影响，超出必要限度，构成侵权。→ **比例小 ≠ 合理使用**，关键看是否覆盖核心表达并产生替代。
- **(2021)京73民终4060号**：短视频"多为涉案作品的内容浓缩和核心看点……甚至可以替代涉案作品"，抗辩不成立。** (2021)沪0115民初25717号**：配音片段上传属"向公众传播"而非个人使用。** (2017)京0105民初10028号**：使用电视剧截图、海报"并未与作品的正常利用相冲突，也没有不合理地损害著作权人的合法利益"，认定合理使用。→ 结论高度个案化。

**9. 判断要素汇总。**综合 7.11、三步检验与国家版权局口径，须同时评估：①引用对象是否已发表；②目的是否为介绍/评论/说明问题（而非让人"看完原片"）；③引用量是否必要最小限度、是否构成新片主体或实质部分；④是否指明作者与作品名称；⑤是否**实质性替代**；⑥**营利性质**（流量分成、广告、带货、引流、企业宣传通常被认定商业性使用）；⑦**创作转化程度**。**不存在"用 X 秒 / X% 以下即安全"的明线规则**。

## 二、六种二创形态风险分级表

| 形态 | 主要风险 | 等级 | 合规要点 |
| --- | --- | --- | --- |
| 整片搬运 / 去水印转发 | 复制权、信息网络传播权、第五十一条 | 🔴 极高 | 禁止，无授权即下架 |
| 切条（化整为零） | 复制/汇编权，剑网重点整治 | 🔴 极高 | 国家版权局明确定性侵权，须授权 |
| "X 分钟看电影"剧情解说 | 实质性替代（图解电影案） | 🔴 极高 | 覆盖主要剧情与关键画面几乎必然侵权 |
| 混剪 / 合集 / 盘点 | 复制权、汇编权，展示核心看点易替代 | 🟠 高 | 引用限于论证所需，原片作辅助 |
| 影评 / 拉片 / 穿帮盘点 | 引用过量、未署名、商用 | 🟡 中（可降 🟢） | 最接近适当引用；控比例、逐条署名 |
| Reaction / 反应视频 | 原片常全程出现，替代风险高 | 🟠 高 | 取得授权或改用极小片段 |
| 恶搞 / 鬼畜 / 戏仿 | 改编权、保护作品完整权、名誉权 | 🟠 高 | 讽刺有空间，不得丑化歪曲 |

**营利性质是风险放大器**：用于广告、带货、企业宣传或账号变现时，三步检验中"影响正常使用/不合理损害"极易成立。

## 三、对剪辑的具体影响

1. 切条、剧情速看、Reaction 直接按"需授权"立项，不指望抗辩。
2. 每个引用片段登记用途（"为说明 XX 问题"）与必要性；片尾、简介、画面三处标注作者与作品名称。
3. **实质替代自测**："看完我的视频，观众还需要看原片吗？"图解电影案已确认 0.5% 也可能侵权。
4. "标注来源/侵删"只满足指明义务，不构成授权；去水印反而加重恶意。
5. 商用一律走书面授权，写明权利种类、地域、期限、可转授；保留创作底稿与素材台账。

## 四、二创合规自查决策树

```
Q0 素材全为原创/已授权/公有领域/兼容 CC？ 是→可发布（留存授权链） 否→Q1
Q1 有书面授权且覆盖「复制+改编+信息网络传播+商用+地域+期限+可转授」？
   是→授权范围内发布（第二十九条权利保留） 否→Q2
Q2 落入第二十四条某一具体情形？ 否→【停止】回 Q1 或换素材 是→Q3
Q3 目的是「介绍/评论/说明问题」而非让人速览原片？
   否→【🔴 停止】搬运、切条、剧情速看终止 是→Q4
Q4 引用为必需最小限度，且不构成新片主体/实质部分/核心看点？
   否→【🔴 停止】压缩引用或改授权 是→Q5
Q5 已指明作者姓名（名称）+ 作品名称？ 否→补正，否则抗辩不成立 是→Q6
Q6 是否影响正常使用/产生实质性替代/不合理损害权利人（三步检验）？
   是→【🔴 停止】 否→Q7
Q7 是否营利（广告、带货、引流、分成、企业宣传）？
   是→【🟠 转商用授权】 否→【🟡/🟢 低风险】保守裁剪＋全量留证后发布
```

**任一步"不确定"，一律按"需授权"处理。**

## 五、自查清单

- [ ] 已判定形态并对照分级表，未把切条/剧情速看当免责
- [ ] 每个引用片段能写出"为说明哪个具体问题"的一句话理由
- [ ] 未使用原片核心剧情、关键画面、高潮段落的连续集合；删除引用后自己评论仍成立
- [ ] 已做实质替代自测；已指明作者与作品名称且可被观众看到
- [ ] 未去水印、未改动权利管理信息；商用项目已取书面授权或改自有素材
- [ ] 已按 7.11 四因素留痕；底稿、来源、授权、沟通记录已归档
- [ ] 未用"只用了 X 秒"作为唯一依据

## 七、待核实与争议点

1. **图解电影案**案号 (2019)京0491民初663号 /(2020)京73民终187号、当事人、"382 幅""0.5%"均来自律所/媒体转述，未取得裁判文书原文，待复核。
2. **(2021)京73民终4060号、(2021)沪0115民初25717号、(2017)京0105民初10028号**及"《陆垚知马俐》葫芦娃案"：均为转述，案号、法院、生效状态待核实。
3. 北京高院《审理指南》为地方法院指引、非司法解释；发布/修订年份、是否被替代待核实。
4. 「12 种情形」旧称 vs 第二十四条 13 项（含兜底项），正式引用应以条文原文为准。
5. "创作转化程度/转化性使用"系美国 fair use 概念，中国法下非法定要件，是否及如何纳入判断缺统一解释。
6. "营利性"认定边界（流量分成、涨粉引流、平台补贴是否一律构成商业性使用）各地口径不一；7.12 仅明确营利性社会培训。
7. Reaction 形态无专门裁判指引，风险分级系依一般原理推演，待核实。
8. 「剑网」后续年度（2024/2025/2026）是否继续列切条、改编合辑为重点，未逐年核实。
9. 国家版权局专家文章属学理/政策解读，非规范性文件，不能作裁判依据直接援引。

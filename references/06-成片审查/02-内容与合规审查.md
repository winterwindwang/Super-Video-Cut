# 内容与合规审查（Editorial & Compliance QC）

> 分类：成片审查 | 主题：版权权属、内容合规、字幕文案与发布风险审查 | 整理日期：2026-11-10 | 适用：任何对外发布或商用的成片；与技术审查 `01-技术规格审查清单.md` 并行执行

> ⚠️ 本文件为制作流程自查参考，**不构成法律意见**。法规、司法解释、平台规则会变化，高风险或商用项目须由法务/专业律师复核。完整法条与案例见 `../05-版权法规/`。

---

## 一、为什么这道关卡必须独立存在

技术审查回答「文件能不能播」，内容审查回答「**能不能发、发了会不会出事**」。二者不互相覆盖：一个音画完美、响度合规的片子，可能因一段未授权 BGM、一个未打码的路人正脸、一句绝对化用语而被下架、索赔或行政处罚。

审查时点建议前置两次：**粗剪完成后做一次版权预检**（换素材成本最低），**定稿导出前做一次终审**。

## 二、版权与授权链审查

### 2.1 建立素材台账

每一项出现在时间线上的外部素材都要能回答五个问题，缺一即为红色阻断项：

| 字段 | 说明 |
| --- | --- |
| 素材来源 | 具体站点 / 拍摄者 / 授权方，精确到 URL 或合同编号 |
| 权利类型 | 画面、音乐（词曲 + 录音 + 表演三层）、音效、字体、肖像、声音 |
| 授权范围 | 商业/非商业、地域、期限、平台、可否二改、可否转授权 |
| 授权凭证 | 许可协议、发票、下载记录、平台曲库截图（含时间戳） |
| 署名与标注 | 是否要求署名、是否需保留版权信息 / 水印 |

### 2.2 逐项检查表

- [ ] **音乐**：词曲著作权、录音制作者权、表演者权是否分别覆盖；平台曲库是否限「仅本平台 / 非商用」；授权期限是否覆盖发布周期；跨境发布是否受地域封锁。
- [ ] **音效 / 采样**：确认来源许可；免版税（Royalty-Free）≠ 无版权；CC 协议的 BY / NC / ND / SA 条件逐条满足（带货、流量分成是否算 NC 的商业性使用存在争议）。
- [ ] **影视/他人视频片段**：是否落入「适当引用」；是否指明作者姓名与作品名称；是否实质替代原作；切条搬运、不添加新表达的合辑风险最高。
- [ ] **图片 / 字体**：字体单字是否构成美术作品存在司法分歧，商用字体务必取得商用授权；图库许可是否覆盖视频用途与分发量。
- [ ] **肖像 / 声音 / 隐私**：出镜者书面授权（含用途、期限、地域、可否用于广告）；路人正脸与可识别车牌/门牌/手机号需打码；未成年人出镜需监护人同意并注意广告代言限制。
- [ ] **权利管理信息**：**不得去除或遮盖水印、版权标识、元数据**——删除权利管理信息本身是独立侵权事由。
- [ ] **AI 生成内容**：训练/克隆素材的授权、语音克隆的本人同意、生成内容的标识义务、平台对 AI 内容的申报要求。
- [ ] **品牌与商标**：竞品 LOGO、产品包装的附带性露出是否会被认定为商标性使用；不使用他人商标作标题/封面主视觉。

### 2.3 风险分级

| 级别 | 判定 | 处理 |
| --- | --- | --- |
| 🔴 红 | 无授权凭证的核心素材、切条搬运、去除水印、未成年人无授权、明显绝对化用语 | **阻断发布**，替换素材或取得授权后重新审查 |
| 🟡 黄 | 授权范围模糊、平台曲库地域限制、二创引用比例偏高、AI 内容未标识 | 法务确认 / 补标识 / 降低引用比例，留书面结论 |
| 🟢 绿 | 自有拍摄 + 已授权素材 + 完整台账 | 归档台账与凭证，通过 |

## 三、内容合规审查

| 维度 | 检查点 | 关联文档 |
| --- | --- | --- |
| 广告与营销 | 绝对化用语（「最」「第一」「国家级」等）、虚假宣传、功效断言、数据与引用出处、比较广告、医疗/金融/教育等特殊行业资质 | `../04-分类型剪辑/03-广告与品牌宣传片.md`、`../05-版权法规/` |
| 事实核查 | 人名职务、时间地点、数字与单位、引语是否断章取义、图表数据来源与统计口径 | —— |
| 剪辑伦理 | 是否通过剪切改变受访者原意；是否把不同时间/场合的语句拼成一句；摆拍是否标注；同期声与画面是否错配 | `../04-分类型剪辑/02-访谈纪录片与人物纪实.md` |
| 隐私与个人信息 | 人脸、姓名、工牌、快递单、聊天记录、定位、病历等可识别信息 | `../05-版权法规/04-肖像字体素材与人格权.md` |
| 平台规则 | 各平台对二创、搬运、诱导互动、站外引流、医疗/财经内容的专门规则；规则会变，发布前查官方最新文本 | `../05-版权法规/05-平台规则与海外合规.md` |
| 地图与标识 | 涉及地图时使用合规底图与正确国界标注 | 依现行测绘与地图管理要求 |
| 未成年人 | 出镜授权、形象使用、不得作为广告代言人、不得暴露校徽/家庭住址 | `../05-版权法规/04` |
| 跨境发布 | 音乐地域授权、DMCA / Content ID、欧盟 DSM 第 17 条、数据出境与 GDPR | `../05-版权法规/05` |
| AI 标识 | 生成式/深度合成内容的显著标识与显式声明、平台申报 | 依《生成式人工智能服务管理暂行办法》《互联网信息服务深度合成管理规定》等现行规定复核 |

## 四、字幕、文案与可访问性审查

- [ ] 字幕全文校对：错别字、多音字、人名/术语统一、数字与单位、中英文空格、标点。
- [ ] 时间轴：无重叠、无倒序、单条停留时长达标、末条不超片长、不跨镜头硬切硬断。
- [ ] 双语/多语言：译文准确、无文化误读、语言标签正确（ISO 639）、轨道命名清晰。
- [ ] 无障碍：听障字幕（SDH）是否标注说话人与关键音效；对比度是否足够；重要信息是否仅靠颜色或仅靠声音传达。
- [ ] 画面内文字：标题、花字、角标、二维码的有效期与可扫描性；竖屏 UI 安全区无遮挡。
- [ ] 片尾：版权声明、出品方、授权与致谢、免责声明是否齐全且可读时长足够。

## 五、审查工作流与留痕

```
粗剪定版
  → ① 导出素材台账，逐项核对授权凭证（版权预检）
  → ② 内容合规自查（广告用语 / 事实 / 隐私 / 平台规则）
  → ③ 字幕文案校对 + 无障碍检查
  → ④ 技术审查（见 01）
  → ⑤ 风险分级：红项阻断 / 黄项书面结论 / 绿项通过
  → ⑥ 填写 03-审查表模板.md，记录审查人、日期、版本号、结论
  → ⑦ 归档：成片 + 工程 + 素材台账 + 授权凭证 + 审查表，一并保存
  → ⑧ 发布后按平台反馈复核（下架/限流/版权申诉）
```

**留痕要求**：审查结论必须落到书面记录。「口头说没问题」在纠纷中没有任何价值。授权凭证与审查表的保存期限应不短于作品发布周期 + 争议追溯期。

## 六、常见错误与排查

| 现象 | 根因 | 处理 |
| --- | --- | --- |
| 用了平台「免费商用」音乐却收到版权主张 | 曲库授权限本平台 / 限非商用 / 账号主体不符 | 复核曲库协议原文，改用可跨平台商用授权并留凭证 |
| 二创被判侵权 | 引用比例过高、未署名、实质替代原作 | 提高原创解说比重、缩短引用、明确署名与评论目的；仍高风险则不用 |
| 受访者投诉「我不是这个意思」 | 跨句拼接改变了语义 | 恢复语境或补录，取得受访者对成片的书面确认 |
| 字体收到索赔函 | 使用未购买商用授权的字库 | 换用开源授权字体（如 SIL OFL）或补购授权 |
| 路人正脸引发隐私投诉 | 未打码且可识别 | 模糊处理或取得授权；街拍亦不当然免责 |
| 广告被平台拒审 | 绝对化用语 / 缺资质 | 逐句比对禁用表述，补齐行业资质证明 |
| 发布后音量被压、字幕丢失 | 只做了文件检查未做平台实测 | 上传预览验证，见 `01-技术规格审查清单.md` 的 L4 |
| 审查做了但说不清 | 无台账、无签字记录 | 强制使用 `03-审查表模板.md` 并归档 |

## 七、终审速查（打印贴墙版）

- [ ] 素材台账齐全，每一项外部素材都有授权凭证
- [ ] 音乐三层权利 + 平台/地域/期限限制已核
- [ ] 无去水印、无未授权肖像/声音/隐私信息
- [ ] 二创引用符合适当引用与署名要求，非实质替代
- [ ] 无绝对化用语、无无出处数据、无断章取义
- [ ] 字幕全文校对、时间轴合法、可访问性达标
- [ ] AI 生成内容已按现行规定标识与申报
- [ ] 片尾版权与授权声明齐全
- [ ] 风险分级完成，红项已清零、黄项有书面结论
- [ ] 审查表填写签字并随工程归档
- [ ] 高风险项目已获法务/律师复核

## 一、核心原理与概念对比

素材风险来自三层独立权利，**免费许可通常只覆盖第一层**：

| 权利层 | 内容 | 免费许可是否覆盖 |
| --- | --- | --- |
| 著作权 | 文件的复制、改编、分发 | 通常覆盖（按条款） |
| 肖像权 / 隐私权 | 画面中可识别的人物 | **通常不覆盖** |
| 商标权 / 物权 | Logo、品牌、建筑、产品外观 | **通常不覆盖** |

### 许可类型速辨

| 类型 | 含义 | 商用要点 |
| --- | --- | --- |
| CC0 | 公有领域贡献，最宽松 | 可商用、可改、免署名 |
| CC-BY | 署名即可 | **必须署名** |
| CC-BY-SA | 署名 + 相同方式共享 | 衍生需同许可，有传染风险 |
| CC-BY-NC | 非商业 | **禁止商用** |
| 自有库许可 | Pexels / Pixabay / Unsplash 自制条款 | 逐条读官方页 |
| Royalty-free | 授权后按范围使用 | **不等于免费/放弃版权**，看平台、地域、时长 |
| Sync license | 音乐与影像结合的同步权 | 需单独取得 |
| Editorial use only | 仅编辑/新闻用途 | **禁止商业广告** |
| Rights-managed | 按用途/时长/地域计价 | 超范围即违约 |

**重要澄清（「待核实」）**：大量第三方文章把 Pexels / Pixabay / Unsplash 写成「遵循 CC0」，但其官方页均使用**自有 Content License**，与 CC0 有实质差异（禁止 Standalone 转售、禁止作商标）。以官方页为准，**授权需自行复核**。

### 2.2 Pixabay Content License（官方页摘要）

| 允许 | 禁止（Prohibited Uses） |
| --- | --- |
| 免费使用、**无需署名**、可改编为新作品 | Standalone 独立销售/分发：未施加创作努力、与原形态实质相同 |

| — | 不得用作商标、商号、服务标记 |

官方两句必须记住：**「只有完整版 Content License 具有法律约束力」**（全文在 pixabay.com/service/terms/）；**「某些内容可能受第三方知识产权（版权、商标、外观设计、精神权利、隐私权/肖像权等）约束，由使用者自行核查是否需要第三方同意或许可」**。这正是「授权需自行复核」的官方依据。

### 2.3 SIL Open Font License 1.1（官方全文核实）

| 允许 | 五项条件 |
| --- | --- |
| 使用、研究、复制、合并、**嵌入**、修改、再分发、销售副本 | ① 字体或任何组件**不得单独售卖** |
| 可与软件捆绑、嵌入、再分发与销售 | ② 每份副本须含版权声明与许可全文 |
| 可用于商业视频、广播、印刷文档 | ③ 修改版不得用 **Reserved Font Name (RFN)**，除非书面许可 |
| — | ④ 不得用版权持有人/作者名义为修改版背书 |
| — | ⑤ 字体及衍生必须整体按 OFL 分发，不得改其他许可 |

**关键豁免**：条件 ⑤ 明确不适用于「用该字体创建的文档」，故用 OFL 字体渲染的视频/图片/PDF 可正常商用。违反任一条件许可自动终止；字体 AS IS 无担保。OFL 1.1 文本日期 2007-02-26，官网 FAQ 版本 1.1-update8（2026-11），**版本细节「待核实」**。

### 2.4 授权需自行复核清单（可执行）

- 用途：商用/非商用、平台、地域、时长、媒介、二次分发
- 内容：可识别人脸、品牌、商标、私人场所、艺术品
- 许可：打开**官方完整版**逐条对照 Prohibited Uses
- 证据：许可页 + 详情页截图、下载日期、作者、是否修改
- 音乐：署名义务、平台限定、sync 权、Content ID
- 字体：许可文件、OFL 五条件、RFN、是否单独售卖
- **结论：授权需自行复核**，本文不替代官方条款与法务判断

## 五、操作步骤与工作流（含本机 ffmpeg 8.1.2 实测通过的命令）

授权自查 SOP：明确用途 → 打开官方许可页全文 → 逐条核 Prohibited Uses → 检查人像/商标 → 截图留档 → 建台账 → 字体与音乐单独复核 → 交付前再核一遍。

```bash
# ① 查看素材内嵌版权/来源元数据
ffprobe -v error -show_entries format_tags -of json asset.mp4

# ② 批量生成素材清单（分辨率、帧率、时长、体积）
for f in assets/*.mp4; do
  echo "== $f =="
  ffprobe -v error -show_entries format=duration,size:stream=codec_name,width,height,r_frame_rate -of csv "$f"
done

# ③ 抽首帧做台账缩略图，便于举证
ffmpeg -y -ss 0 -i asset.mp4 -frames:v 1 -q:v 2 thumbs/asset.jpg

# ④ OFL 要求许可全文随字体副本分发
mkdir -p deliver/fonts && cp fonts/OFL.txt deliver/fonts/
```

台账字段：`来源 URL | 作者 | 站点 | 许可类型 | 许可页 URL | 下载日期 | 是否修改 | 署名文案 | 投放平台 | 截图路径`。

## 六、常见错误与排查

| 现象 | 根因 | 修复 |
| --- | --- | --- |
| 以为「免费商用 = 无责任」 | 忽略肖像权/商标权 | 逐条核 Prohibited Uses，人像品牌另取授权 |
| 把 Pexels/Pixabay 当 CC0 | 二手文章过时（「待核实」） | 以官方许可页为准 |
| 素材原样印在商品上卖 | 违反 Standalone 禁令 | 先实质修改或换授权 |
| 用含 Logo 画面做商品广告 | 商标权不在许可内 | 换素材或取得品牌授权 |
| 可识别人物出现在负面语境 | Pexels 明确禁止 | 换素材 |
| Freesound 用了 CC-BY-NC 做商用 | 逐条许可没看 | 只留 CC0 / CC-BY |
| Uppbeat / Freepik 忘署名 | 免费档有署名义务 | 按许可贴进简介或片尾 |
| 单独售卖 OFL 字体 | 违反条件 ① | 只能随软件/作品捆绑 |
| 修改 OFL 字体仍用原名 | 违反 RFN 条件 ③ | 改用新字体名 |
| 以为 OFL 传染成片 | 误读条件 ⑤ | 官方明确排除「用字体创建的文档」 |
| 微软雅黑/方正商用被索赔 | 授权不清（「待核实」） | 换明确免费商用字体并归档许可 |
| 平台曲库音乐发到别的平台 | 授权平台限定 | 重看条款或换曲 |
| 误下 Sponsored 付费图 | 聚合页混广告 | 进详情页确认免费标记 |

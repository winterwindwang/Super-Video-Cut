# 参考视频多维评估框架（核心卷）

> 分类：RSI自进化 | 主题：剪辑手法 / 音效 / 场景三大核心维度 + 四段式说明强制约束 | 整理日期：2026-11-10 | 适用：收到「参考某热门视频风格剪辑」后的 S3–S5 阶段

> ⚠️ 本文为创作流程参考，**不构成法律意见**；涉及授权与合规的决策请查阅 05-版权法规卷并由法务复核。

> ⚠️ 本卷的硬性要求只有一句：**每一条评估都必须给出说明**。没有说明的判断一律丢弃，不得进入风格指纹，也不得作为剪辑依据。

---

## 一、为什么必须逐维度评估并给说明

「风格」不是一个整体印象，而是一组可测量、可复现的参数组合。只说「这条片节奏快、音乐燃、色调暖」有三个问题：无法复现（快是多少）、无法审查（成片像不像没标准）、无法归因（效果不好不知道改哪个）。

因此评估必须同时满足三个条件：**分维度**（不混在一起）、**有证据**（带时间码或可复现数值）、**给说明**（解释观察到什么、凭什么、为什么这么剪、我要怎么用）。

---

## 二、说明强制约束（Explain-or-Discard）

每一条评估条目必须填满五段，缺任一段即整条作废：

| 段 | 要求 | 反例 → 正例 |
| --- | --- | --- |
| ① **观察** | 看得见/听得见的事实，带时间码或数值；不夹杂评价 | ✗「节奏很快」→ ✓「00:00–00:03 共 4 次硬切，平均镜头 0.75 s」 |
| ② **依据** | 用什么得出：客观命令 / 抽帧 / 逐帧听 / 波形；标证据等级 | ✓「`select scene` 切点表 + 抽帧拼图第 1 行，E1+E2」 |
| ③ **推断** | 解释这一手法的意图与效果，允许是假设但须标明 | ✓「短镜头堆叠用于开场信息密度，让观众在前 3 秒抓到 3 个卖点」 |
| ④ **动作项** | 落到本次剪辑的可执行参数；无动作项则该条无价值 | ✓「本项目开场 3 s 用 0.8–1.2 s 镜头 ×3，第三切点置于抬手动作峰值前 1–2 帧」 |
| ⑤ **置信度** | 高 / 中 / 低 + 一句理由；低置信度不得作为硬约束 | ✓「高：切点由 E1 客观提取，且该模式在片中出现 3 次」 |

**完整示例（维度 A）**

> **A3 切点依据**
> ① 观察：00:07.12 硬切，由中景切至产品特写；切点位于人物抬手动作启动后第 3 帧；全片 31 个切点中 22 个落在动作或台词断点上。
> ② 依据：`reference_probe.sh` 输出的切点表（E1）+ 00:07.08/00:07.12 逐帧比对（E2）。
> ③ 推断：采用「动作接动作」的隐形剪辑，用动量跨接缝，同时把信息焦点从人物转到产品；断点对齐让密集切换不显杂乱。
> ④ 动作项：本项目所有产品揭示镜头的切点置于动作峰值前 1–2 帧；其余切点对齐台词/呼吸断点，避免随机卡点。
> ⑤ 置信度：高（E1 可复现，模式重复 22/31 次）。

**被丢弃的反例**

> ✗「这个视频剪辑很流畅，转场自然，很有电影感，值得学习。」
> 缺观察数值、缺依据、缺动作项、缺置信度；「流畅/电影感」是评价而非事实 → **整条丢弃，不进指纹**。

## 三、证据等级与强度量表

| 等级 | 含义 | 可否作为硬约束 |
| --- | --- | --- |
| **E1 客观可复现** | ffprobe/ffmpeg 数值、切点表、响度、色彩统计，别人重跑能得到相同结果 | 可 |
| **E2 可指认事实** | 带时间码的人工观察（画面内容、台词、音效听感），可被第三方复核 | 可（需 ≥2 处印证） |
| **E3 解释性推断** | 对意图、受众、情绪的推断 | 否，只能作参考并标明为推断 |
| **E4 猜测/仅描述** | 无视频、仅凭文字描述或印象 | 否；强制标「低」，且须在 S6 告知用户 |

**强度量表 0–4 表示特征强度/密度，不表示好坏**（避免把主观审美当分数）：

| 值 | 含义 |
| --- | --- |
| 0 | 未出现 |
| 1 | 偶发（<10% 时长或 <2 次） |
| 2 | 存在但不主导（10–30%） |
| 3 | 明显、贯穿（30–60%） |
| 4 | 主导特征（>60%）或全片结构性手法 |

每条评估记录 `强度` + `置信度` + `证据等级`，三者独立。强度 4 但置信度低的条目不能当硬约束。

## 四、七大维度总览

| 编号 | 维度 | 地位 | 主要手段 | 输出字段前缀 |
| --- | --- | --- | --- | --- |
| **A** | **剪辑手法** | ★核心 | 客观切点表 + 逐帧观察 | `edit.*` |
| **B** | **音效与声音设计** | ★核心 | 响度测量 + 带时间码听辨 | `audio.*` |
| **C** | **场景与画面** | ★核心 | 抽帧拼图 + 色彩统计 + 场景清单 | `scene.*` |
| D | 字幕与图文 | 扩展 | OCR / 人工校读 | `caption.*` |
| E | 叙事结构与情绪曲线 | 扩展 | 段落时间轴 + 推断 | `narrative.*` |
| F | 平台与受众语境 | 扩展 | 规格 + 发布环境 | `context.*` |
| G | 合规与可复制性边界 | **强制** | 05 卷 + 思想/表达二分法 | `constraint.*` |

A/B/C 必须逐子项评估；D/E/F 至少各出 2 条带说明的判断；G 不是描述性维度，而是**对 A–F 每条动作项的过滤器**（见 §八）。

## 五、维度 A · 剪辑手法（★）

| 子项 | 观察什么 | 测量方法 | 说明侧重点（③推断必须回答） | 指纹字段 |
| --- | --- | --- | --- | --- |
| A1 镜头时长分布 | 中位数、均值、p90、最短/最长；分段差异 | E1 切点表 → `awk` 算相邻差；学术上镜头时长常呈长尾分布，**以中位数而非均值为节奏代表** | 为什么这个时长？与信息密度/情绪的关系 | `edit.shot_median_s`, `edit.shot_p90_s` |
| A2 切换密度曲线 | 每 10 s 的 cuts/min；开场/中段/结尾对比 | E1 切点表分桶 | 密度变化服务于什么（钩子/铺垫/高潮） | `edit.cut_density_per_min`, `edit.density_curve` |
| A3 切点依据 | 动作峰值 / 视线 / 台词断点 / 节拍 / 信息拐点各占多少 | E1 切点 + E2 逐帧；统计占比 | 为何选这类切点，隐形还是强调 | `edit.cut_anchor_distribution` |
| A4 转场类型与时长 | 硬切 / 叠化 / 遮罩 / 甩镜 / 匹配转场占比与帧数 | E2 逐帧比对转场前后；叠化可看双影帧数 | 转场是连接、分隔还是修辞 | `edit.transition_mix`, `edit.dissolve_frames` |
| A5 景别序列与组接 | WS→MS→CU 的推进模式、是否守 180°/30°、越轴处理 | E2 抽帧拼图标景别 | 景别变化如何控制注意力 | `edit.scale_progression` |
| A6 镜头内动能 | 推拉摇移、手持、稳定器、主体运动量 | E2 逐段观察；可用 `signalstats`/运动估计辅助 | 动能与剪辑节奏是叠加还是互补 | `edit.camera_motion` |
| A7 J-cut / L-cut | 音频先入/后出的次数与帧偏移 | E2 波形与切点对照（8–24 帧为常见起调值） | 声音桥如何软化接缝 | `edit.jl_cut_frames` |
| A8 B-roll 占比 | 覆盖时长比例、插入位置、是否盖住跳切 | E2 时间线标注 | B-roll 是补信息还是遮瑕疵 | `edit.broll_ratio` |
| A9 卡点对齐 | 切点与音乐节拍的帧差分布 | E1 切点 + E2 波形/节拍标注 | 是否全程卡点，还是只在副歌 | `edit.beat_align_frame_error` |
| A10 帧率、升格、变速 | 25/30/50/60 fps；慢动作段与用途 | E1 ffprobe `r_frame_rate`；E2 找出变速段 | 变速服务于强调还是过渡 | `edit.fps`, `edit.slowmo_segments` |

**A 维度特别说明要求**：必须回答「如果只允许改变一个参数，哪一个是这条片节奏的骨架？」——这是后续映射的优先级依据。

## 六、维度 B · 音效与声音设计（★）

| 子项 | 观察什么 | 测量方法 | 说明侧重点 | 指纹字段 |
| --- | --- | --- | --- | --- |
| B1 音乐结构与参数 | BPM、调性/情绪、段落（前奏/主歌/副歌）、是否循环 | E2 听辨 + 打拍；E1 可用 BPM 工具辅助 | 音乐为何选这个能量曲线 | `audio.bpm`, `audio.mood` |
| B2 音乐进出点 | 起止时间、淡入淡出、副歌与画面高潮的对齐 | E2 波形 + 时间码 | 音乐如何承担结构而非铺底 | `audio.music_in_s`, `audio.drop_align_s` |
| B3 人声类型与占比 | 口播 / 对白 / 无人声；语速、音色、情绪 | E2 听辨 + 转写字数/时长 | 人声是主信息还是辅助 | `audio.voice_type`, `audio.speech_ratio` |
| B4 音效密度与类型 | 每 10 s 音效次数；whoosh / impact / UI / 环境 / Foley 分类 | E2 带时间码听辨计数 | 音效是强化切点还是独立叙事 | `audio.sfx_per_10s`, `audio.sfx_types` |
| B5 音效与切点耦合 | 有切点处是否配音效、比例多少 | E1 切点表 × E2 音效表交叉 | 耦合度决定「打击感」从哪来 | `audio.sfx_cut_coupling` |
| B6 电平关系与 ducking | 对白/音乐/音效相对电平、人声出现时音乐下压量 | E1 `ebur128` 分段 + `volumedetect`；E2 听辨 | 如何保证可懂度 | `audio.music_duck_db` |
| B7 响度与真峰值 | Integrated LUFS、LRA、True Peak | **E1** `ffmpeg -af ebur128=peak=true`（读末尾 Summary） | 交付平台决定目标，不是「越大声越好」 | `audio.integrated_lufs`, `audio.true_peak_dbtp` |
| B8 声音桥与跨场 | 台词/音效跨切点延续、J/L-cut 音频侧 | E2 波形对照 | 与 A7 是否配套 | `audio.sound_bridge` |
| B9 静音与留白 | 刻意静音位置、时长、前后文 | **E1** `silencedetect=noise=-40dB:d=0.5` + E2 确认 | 留白是制造反差还是失误 | `audio.intentional_silence` |
| B10 频段与空间 | 低频厚度、齿音、立体声宽度、单声道兼容 | E2 听辨；E1 `highpass/lowpass + volumedetect` | 目标播放环境（手机/耳机）如何影响混音 | `audio.playback_target` |

**B 维度特别说明要求**：必须区分「音乐驱动剪辑」还是「剪辑驱动音乐」。判断方法：看切点是否系统性落在节拍上（A9 帧差小且集中）；这决定本项目先定音乐还是先定画面。

## 七、维度 C · 场景与画面（★）

| 子项 | 观察什么 | 测量方法 | 说明侧重点 | 指纹字段 |
| --- | --- | --- | --- | --- |
| C1 场景清单 | 编号 / 时间码 / 地点 / 人物 / 场景功能 | E2 抽帧拼图 + 全片通看 | 每个场景承担什么叙事任务 | `scene.list` |
| C2 场景切换频率 | 场景数与时长分布、段落划分 | E1 `scdet` / `select scene` 辅助 + E2 归并 | 场景密度与信息容量的关系 | `scene.count`, `scene.duration_dist` |
| C3 构图偏好 | 三分法/居中/对称、主体占比、留白方向 | E2 抽帧逐格标注 | 构图是否服务于字幕与竖屏 UI | `scene.composition` |
| C4 机位与景别习惯 | 平视/俯仰、常用景别、过肩 | E2 观察 | 视角建立何种观看关系 | `scene.camera_height` |
| C5 色调与光线 | 高调/低调、色温冷暖、对比度、硬光/柔光 | E2 观察 + E1 色彩统计 | 色调如何匹配情绪与品类 | `scene.lighting_key`, `scene.color_temp` |
| C6 色彩统计 | 平均亮度、饱和度、主色、场景间跳变 | **E1** `signalstats` 输出 `YAVG/SATAVG` 等 | 色调是全局统一还是分段反差 | `scene.yavg`, `scene.satavg` |
| C7 运动与稳定 | 运镜方式、防抖、画面内运动量 | E2 观察 | 与 A6 是否一致 | `scene.motion_level` |
| C8 画幅与安全区 | 比例、遮幅、字幕/UI 安全区、竖屏顶部底部遮挡 | E1 ffprobe + E2 目测 | 平台 UI 会吃掉哪部分画面 | `scene.aspect`, `scene.safe_area` |
| C9 画面内元素 | 花字、道具、品牌露出、人物关系与动线 | E2 标注 | 哪些是可借鉴的结构、哪些是受保护的表达 | `scene.on_screen_elements` |
| C10 场景与叙事功能 | 建立 / 推进 / 转折 / 收尾 的时间占比 | E2 结构时间轴（**E3 推断**，须标明） | 结构比例如何迁移到不同素材 | `scene.narrative_role_ratio` |

**C 维度特别说明要求**：必须列出「哪些场景特征依赖具体内容、无法迁移」。例如「海边日落」是内容，不能迁移；「每 8–12 s 换一次场地以维持新鲜感」是结构，可以迁移。这条区分是防止复制表达的第一道滤网。

## 八、扩展维度与强制维度 G

- **D 字幕与图文**：单行字数/行数、停留时长、出现时机（是否比语音早）、字体与描边、花字频率、是否承载笑点或信息。判据见 `../03-字幕系统/`。
- **E 叙事结构与情绪曲线**：段落时间轴（钩子/铺垫/转折/高潮/收尾）、情绪强度曲线、信息揭晓顺序。此维度多为 E3 推断，须明确标注。
- **F 平台与受众语境**：画幅、时长、首帧、前 3 秒钩子、封面、目标播放环境、平台响度归一化。判据见 `../04-分类型剪辑/`。
- **G 合规与可复制性边界（强制）**：对 A–F 的每一条动作项做二选一打标：
  - `transferable: parameter` — 参数/结构，可写入指纹并迁移（如「镜头中位数 1.8 s」）。
  - `protected: expression` — 具体表达，禁止迁移（如原片台词、独特花字图形、标志性镜头调度、原声音乐）。
  - 依据：思想与表达二分法；实质性相似比较的是表达中的取舍、选择、安排、设计。参考热门视频「接触」要件几乎必然成立，因此一律从严。
  - 任何标 `protected` 的条目不得出现在剪辑方案里；发现已出现即回退到 L1 重新评估。

## 九、评估顺序与输出物

```
S2 客观探测（reference_probe.sh）
   → 规格 / 切点表 / 镜头时长统计 / 响度 / 静音 / 色彩统计 / 抽帧拼图
S3 观察
   → 全片 1.0× 通看 2 遍（一遍看画面、一遍只听声音）+ 关键段逐帧
S4 评估
   → A/B/C 逐子项填表（每项五段式说明），D/E/F 各 ≥2 条，G 逐条打标
S5 汇总
   → ① 参考视频评估表.md（完整）
      ② 风格指纹 YAML（只含 transferable 条目）
      ③ 一页结论：3 条最关键特征 + 3 条不可迁移项 + 置信度总评
S6 用户确认门
   → 未确认不进入剪辑
```

**输出物 ③ 的写法**：先给「我观察到什么 / 我打算怎么用到你的素材上 / 我判断不准的是哪几点」，再请用户确认。不要先给成片。

## 十、常见错误

| 错误 | 后果 | 纠正 |
| --- | --- | --- |
| 用均值描述镜头时长 | 长尾分布下均值失真 | 用中位数 + p90 |
| 把 `scdet` 的每个高分当一次剪辑 | 快速摇镜、闪光会误报 | 与 `select scene` + 人工逐帧交叉验证 |
| 「音乐很燃」当 B 维度结论 | 无动作项 | 拆成 BPM、进入点、副歌对齐、响度 |
| 把「海边日落」写进指纹 | 复制内容而非风格 | 过 G 过滤器，只留结构参数 |
| 静音段一律当缺陷 | 可能是刻意留白 | `silencedetect` 后必须人工确认 |
| 低置信度条目当硬约束 | 后续偏差归因全错 | 置信度低 → 标为假设、不进指纹必填区 |
| 评估项只写结论不写依据 | 无法复核、无法自进化 | 五段式说明，缺一作废 |
| 全片只看抽帧拼图 | 漏掉声音与节奏细节 | 抽帧只用于 C 维度，A/B 必须通看通听 |

# 从风格指纹到剪辑方案的映射

> 分类：RSI自进化 | 主题：参数迁移规则、冲突消解、素材适配与偏差容忍 | 整理日期：2026-11-10 | 适用：S6 用户确认通过后的 S7 阶段；产出可直接执行的时间线方案

> ⚠️ 本文为创作流程参考，**不构成法律意见**；涉及授权与合规的决策请查阅 05-版权法规卷并由法务复核。

---

## 一、映射的本质与边界

风格指纹描述的是**参考视频的参数**，而剪辑方案要装在**你自己的素材、时长、平台和合规要求**上。映射不是照抄数值，而是「在约束下尽量逼近相对关系」。

举例：参考片镜头中位数 1.8 s，但你的素材全是 8 s 以上的长镜头、且只有 12 条。直接照搬 1.8 s 会把每条素材切碎、语义断裂。正确做法是保留**相对关系**（开场密、结尾疏，密度比约 3:1），把绝对时长按素材可行区间缩放（如 2.6 s / 5.0 s）。

**三条铁律**：
1. 只迁移 `transferable: parameter`，`protected: expression` 永不进入方案。
2. 相对关系优先于绝对数值；绝对数值要让位于素材的物理约束。
3. 任何一条映射都要能回答「如果不这么做会怎样」——答不上来的规则不写入方案。

## 二、冲突消解优先级（从高到低）

当指纹要求与其他约束打架时，严格按此顺序裁决，并把裁决理由写进方案：

| 优先级 | 约束 | 举例 |
| --- | --- | --- |
| P0 | 法律与合规（05 卷、G 过滤器、平台规则） | 指纹里出现原片音乐 → 直接剔除，不做讨论 |
| P1 | 用户明确要求（S6 确认内容 + 本次 brief） | 用户说「不要旁白」→ 覆盖指纹的 `speech_ratio: 0.71` |
| P2 | 交付规格与 06 卷审查标准 | 响度必须 −14 LUFS / ≤ −1 dBTP，覆盖指纹实测值 |
| P3 | 素材的物理约束 | 可用镜头数、时长、画质、有无音轨 |
| P4 | 指纹中 `confidence: 高` 的 active 规则 | 镜头时长中位数、切换密度曲线 |
| P5 | 指纹中 `confidence: 中` 的 active 规则 | J/L-cut 帧偏移、ducking 量 |
| P6 | `candidate` 规则与 `hypotheses` | 仅影子记录，不驱动剪辑 |
| P7 | 默认经验值（01–04 卷） | 上述都无规定时的兜底 |

每次冲突都要留痕：`冲突项 / 采纳方 / 被覆盖方 / 理由 / 期望影响`。这些留痕是 L5 误差归因的重要输入——如果某条规则总被覆盖，说明它本身该修订。

## 三、逐维度映射规则表

| 指纹字段 | 映射动作 | 缩放/适配方式 | 冲突时降级 |
| --- | --- | --- | --- |
| `edit.shot_median_s` | 设定基础镜头时长 | 按 `目标时长 / 参考时长` 与可用素材数双向缩放；优先保留开场/中段/结尾的**比例** | 素材不足以支撑 → 放宽至 +50%，并降低切换密度而非切碎语义 |
| `edit.density_curve` | 分配各段切换预算 | 归一化为比例后按目标片长重新分配 cuts 数 | 段落数不同 → 按段数线性插值 |
| `edit.cut_anchor_distribution` | 决定切点选型比例 | 直接迁移比例；动作/台词断点优先 | 无动作素材 → 转为台词断点或信息拐点 |
| `edit.transition_mix` | 转场类型配比 | 直接迁移；叠化帧数按本项目帧率换算 | 平台风格不符 → 提高硬切占比 |
| `edit.scale_progression` | 景别推进模板 | 迁移序列模式，不迁移具体机位 | 素材景别单一 → 用裁切/推近模拟，不得伪造角度 |
| `edit.jl_cut_frames` | 音频偏移帧数 | 按帧率换算（25↔30 fps 需 ×1.2） | 无独立音轨 → 跳过 |
| `edit.broll_ratio` | B-roll 覆盖比例 | 直接迁移 | B-roll 不足 → 优先保住口播跳切处，其余用静帧/图形 |
| `edit.beat_align_frame_error` | 卡点精度 | 只在参考片同样卡点的段落启用 | 音乐不同 → 重新对齐新曲节拍，不硬套时间码 |
| `audio.bpm` / `mood` | 选曲方向 | **只迁移能量与 BPM 区间**，不选同一首曲 | 曲库受限 → 保能量曲线，放弃 BPM 精确值 |
| `audio.music_in_s` / `drop_align_s` | 音乐结构位置 | 按目标片长比例换算（如 12.4/45.2 → 0.27） | 曲目结构不同 → 对齐「首次产品揭示」这一事件而非秒数 |
| `audio.sfx_cut_coupling` | 切点配音效比例 | 直接迁移比例 | 音效库不足 → 保高潮段耦合，其余从简 |
| `audio.music_duck_db` | 侧链下压量 | 直接迁移 | 无人声 → 关闭 |
| `audio.integrated_lufs` / `true_peak_dbtp` | 混音目标 | **P2 优先**：按交付平台目标，不用参考片实测值 | — |
| `audio.intentional_silence` | 留白位置 | 迁移「留白出现在高潮前」这一结构，不迁移秒数 | 节奏不符 → 缩短或取消，并记录 |
| `scene.yavg` / `satavg` / `lighting_key` | 调色方向 | 迁移相对倾向（偏亮/偏暖），不逐帧匹配数值 | 素材色温差异大 → 保统一性优先于绝对数值 |
| `scene.composition` / `safe_area` | 构图与安全区 | 直接迁移（竖屏尤其重要） | 平台不同 → 用目标平台安全区（P2） |
| `scene.duration_dist` / `narrative_role_ratio` | 段落时长比例 | 归一化为比例后套到目标片长 | 素材段落数不同 → 按结构角色合并 |
| `caption.*` | 字幕排版参数 | 直接迁移；文案必须原创 | 语言不同 → 按 `03-字幕系统` 重新定字数 |
| `context.*` | 画幅、钩子、首帧 | P1/P2 优先 | — |
| `constraints.*` | 硬过滤 | 每条方案生成后重跑一次 G 检查 | 命中 forbidden → 整条方案作废重做 |

## 四、素材适配：四种不足情形

| 情形 | 症状 | 处理 | 必须记录 |
| --- | --- | --- | --- |
| 镜头数量不足 | 目标需 30 个切点，素材只够 12 条 | 保留密度曲线形状，整体降密度；用景别变化/裁切增加视觉变化，不靠无意义重复切 | 覆盖率、被放弃的段落 |
| 缺 B-roll | 口播跳切无法遮盖 | 优先在跳切处补；其余用图形、字幕动画、静帧缓动 | 哪些段落裸露跳切 |
| 缺独立音轨 | 无法做 J/L-cut、ducking | 关闭相关规则；**不得用参考片音轨顶替**（P0） | 降级原因 |
| 缺同类型场景 | 参考片 5 个场景，你只有室内 1 个 | 迁移「场景切换频率」这一结构，用机位/景别/光线变化代替场地变化 | 替代手法与预期偏差 |

**降级优先级**：先降绝对数值 → 再降次要维度 → 最后才降核心维度。核心维度（A1 镜头时长、B7 响度、C8 画幅安全区）不得全弃。每次降级都在方案中写明 `预期偏差`，供 L4 审查与 L5 归因使用。

## 六、L4 偏差容忍度（成片 vs 指纹）

导出后必须实测成片并与指纹比对。**容忍度按置信度分级**，不是拍脑袋：

| 指标 | 参考值来源 | 高置信度容忍 | 中置信度容忍 | 测量命令 |
| --- | --- | --- | --- | --- |
| 镜头时长中位数 | `edit.shot_median_s` | ±15% | ±30% | `select scene` + 相邻差统计 |
| 切换密度 | `edit.cut_density_per_min` | ±20% | ±35% | 同上，分桶 |
| Integrated 响度 | `audio.integrated_lufs` | ±1 LU | ±2 LU | `ebur128=peak=true` Summary |
| True Peak | `audio.true_peak_dbtp` | 不得超标 | 不得超标 | 同上 |
| 画幅/帧率 | `context.aspect`, `edit.fps` | 完全一致 | 完全一致 | `ffprobe` |
| 平均亮度倾向 | `scene.yavg` | ±12% | ±25% | `signalstats` YAVG |
| 字幕单行字数 | `caption.chars_per_line` | ±2 字 | ±4 字 | 人工校读 |

超容忍度的项分三类处理：① 有降级记录的 → 视为预期偏差，通过；② 无记录但可修复 → 回炉重剪；③ 反复超差且原因不明 → 记为**归因待办**，交 L5 处理，不擅自调规则。

## 七、常见错误

| 错误 | 后果 | 纠正 |
| --- | --- | --- |
| 把参考片时间码直接套到新片 | 音乐/结构全错位 | 按事件对齐、按比例换算 |
| 用同一首曲子「还原风格」 | 版权风险（P0） | 只迁移 BPM 与能量曲线 |
| 素材不足仍硬凑切换数 | 语义碎裂、观感差 | 降密度、保比例形状 |
| 把参考片实测响度当交付目标 | 平台转码后音量异常 | P2 优先，按平台目标 |
| 降级不留记录 | L5 无法归因，偏差永远查不清 | 每次降级写入 §4 |
| 偏差超限就改指纹 | 掩盖执行问题，属于自欺 | 先查执行，再查映射，最后才查指纹 |
| 低置信度规则当硬约束 | 成片被不靠谱的判断绑死 | `active`/`candidate` 分级 |

# Material Description Card · Human-Readable Filling Guide and Worked Example

> Category: Material memory | Topic: Human-readable MDC filling guide, field-by-field instructions and a complete worked example | Compiled: 2026-11-10 | Applies to: Manual authoring and review of description cards; the machine-readable version is `material-description-card.yaml` in the same directory

> ⚠️ This volume is a creative and engineering process reference and **does not constitute legal advice**; the locations, rights and feedback in the examples are fictional demonstrations, and commercial projects must rely on the underlying documentation.

## 1. How to use this file

| File | Purpose |
| --- | --- |
| `material-description-card.yaml` | **Machine-readable**: copy, fill in, then `validate` + `register` to ingest |
| This file | **Human-readable**: explains how to fill each field and provides one complete example |
| `model-analysis-prompt.md` | The prompt used for the single model request on `MISS` |
| `../01-material-description-card-spec.md` | Authoritative version of the field dictionary, evidence grades and V1–V8 validation rules |

Filling order: `identity` (automatic by tooling) → `style.measured` (local probe) → one model request → manual verification of the four field groups → `usability` rights and privacy → `meta` → `constraints` → `validate`.

## 2. Field-by-field filling notes

| Group | Where people most often get it wrong | Criterion |
| --- | --- | --- |
| `content.summary` | Writing "a beautiful seaside shot" | ≤80 characters, complete subject–verb–object, no evaluative wording: "Fixed-camera empty plate at the seaside at dusk, slow pan right, waves breaking repeatedly against the rocks" |
| `content.timeline` | Providing only a start anchor and an end anchor | ≥3 anchors; one every 15–30 s for material longer than 60 s; each carrying `tc` + `event` + `evidence` |
| `content.affordances` | Writing "good for a nostalgic opening" | Neutral tags only; usage conclusions belong in `topic-adaptation-record.md` |
| `where.place_name` | Filling in a place name because it "looks like Sanya (三亚)" | **Always `null` without on-screen text, a landmark or a shooting record**; put impressions in `inference_note` and mark them E3 |
| `where.environment` | Treating "dusk" as established fact | If it is only inferred from the light, mark it E3 and state the falsification condition |
| `style.measured` | Copying the estimate the model supplied | Must be overwritten with the E1 values from `reference_probe.sh` / `ffprobe` |
| `style.style_notes` | Writing "the grade looks premium" | All five parts present: observation / basis / inference / action item / confidence |
| `usability.rights_status` | Taking the model's "should be fine" at face value | Must be filled in by a human from the rights documentation; `unknown` always blocks |
| `usability.privacy_flags` | Forgetting licence plates and house numbers | Scan the frame item by item and record the timecode |
| `meta` | Not recording the model version | Model name and version, prompt version, analysis date and signer are mandatory |
| `constraints` | Deleting `no_use_until_cleared` | While rights are unclear this switch is a hard block |

## 3. Complete worked example (fictional material, format demonstration only)

> The data below is a demonstration and **is not real material**; the `identity` values illustrate the expected scale and are normally generated by tooling.

```yaml
mdc_version: mdc-v1
material_id: MID-9f3c1a7b02de

identity:
  content_hash: "sha256:9f3c1a7b02de... (64 characters)"
  hash_mode: sampled
  size_bytes: 48231104
  duration_s: 24.0
  container: mov,mp4,m4a,3gp,3g2,mj2
  vcodec: h264
  resolution: 1920x1080
  fps: 25
  pix_fmt: yuv420p
  acodec: aac
  sample_rate: 48000
  channels: 2
  aliases: [海边日落_原片, BROLL-SEA-014]
  source_path_hint: "D:/footage/2026-09/sunset-beach-raw.mp4"
  first_registered: "2026-11-10"
  last_verified: "2026-11-10"

content:
  summary: "Fixed-camera empty plate, seaside dusk, slow pan right, surf on rocks, no people"
  subjects: [rocks, sea surface, cloud layer, distant boat silhouette]
  actions: [waves surging and receding, clouds drifting slowly, camera panning slowly right]
  timeline:
    - {tc: "00:00:00.000", event: "Sea horizon and cloud layer fill the frame, sky occupies roughly 2/3", evidence: E2}
    - {tc: "00:00:07.500", event: "Rocks enter from the lower right, first clearly visible wave impact", evidence: E2}
    - {tc: "00:00:15.000", event: "A small boat silhouette appears in the distance, light continues to fall", evidence: E2}
    - {tc: "00:00:23.000", event: "Shot ends, no subtitles and no end card", evidence: E2}
  spoken:
    has_speech: no
    language: ""
    key_lines: []
    transcript_ref: ""
  onscreen_text: []
  affordances: [empty plate, ambient atmosphere]
  notable_absences: [no speech, no subtitles, no brand exposure, no identifiable faces, no on-screen text]

where:
  setting_type: outdoor
  place_name: null                 # no street sign or landmark in frame, client supplied no shooting record
  place_basis: "none"
  landmarks: []
  environment:
    time_of_day: dusk              # E3 inference: light angle and colour-temperature drift
    weather: cloudy
    season: unknown
    light_direction: backlit
    light_quality: soft
    background: "sea horizon, stratocumulus"
    props: []
  camera:
    position: fixed camera
    angle: eye level
    height: unknown
    movement: slow pan right
    stability: stable
  geo_hint: null
  inference_note: "'Dusk' and 'subtropical coastal feel' are both E3 inferences; basis: YAVG falls from 118 to 76 across 00:00–00:24, and the sun sits off-frame to the left, producing rim light. Falsification condition: if the shooting record shows early morning or studio lighting, this entry is void."

style:
  genre: documentary
  visual:
    shot_sizes: [extreme wide shot]
    composition: "rule of thirds, horizon on the upper third line"
    movement: "slow pan right"
    stability: "stable (tripod or gimbal)"
    color_palette: [orange-gold, grey-blue]
    contrast: medium-high
    saturation: medium
    white_balance: warm
    grain: low
    era_feel: contemporary
  measured:
    shot_median_s: 24.0
    cuts_per_min: 0.0
    integrated_lufs: -16.2
    true_peak_dbtp: -1.4
    yavg: 104
    satavg: 31
  audio:
    music: none
    ambience: "continuous surf and low-frequency wind"
    sfx: []
    voice: "no speech"
    noise_floor: "low, no transient noise"
    has_music_bed: no
  mood: ["Calm (basis: no cuts, constant camera speed, wave sound only)", "Slightly cool (basis: grey-blue cloud layer and low saturation)"]
  rhythm: "Single shot; the rhythm comes from the wave cycle rather than from editing"
  style_notes:
    - observation: "00:00–00:24 single shot, YAVG falls from 118 to 76, rim light persists along the subject edges"
      basis: "E1 signalstats output + rows 1–2 of the E2 frame-contact-sheet"
      inference: "This is an inference: warm-cool contrast from natural backlit dusk light, not artificial lighting"
      action: "When used as an empty plate, do not add a warm LUT, to avoid a colour-temperature break against later interior shots"
      confidence: "Medium: a single clip only, no full-film colour strategy available"
    - observation: "0 cuts in 24 s, cuts_per_min=0.0, surf audio continuous with no edit traces"
      basis: "E1 reference_probe.sh cut table"
      inference: "This is an inference: the clip carries emotion through long-take breathing room rather than information"
      action: "If a short opening under 5 s is needed, cut 00:03 and 00:12 separately to avoid a jump cut between two same-angle shots"
      confidence: "High: objective values are reproducible"
  similarity_caveat: "Resembles the common 'slow-paced travel empty plate'; this is an analogy only and says nothing about source or rights"

usability:
  provenance:
    origin: self_shot
    acquired_from: "Own shoot / 2026-09 location shoot"
    license_ref: "D:/paperwork/2026-09/location-release-and-model-consent.pdf"
  rights_status: cleared
  rights_expiry: null
  releases:
    portrait: na
    minor_guardian: na
    location: yes
    trademark: na
    music: na
  quality_issues:
    - {tc: "00:00:18.200", issue: "slight lens flare upper right, acceptable"}
  edit_notes:
    best_ranges: ["00:00:03-00:00:08", "00:00:12-00:00:19"]
    avoid_ranges: ["00:00:23-00:00:24 (slight shake at the tail)"]
    handles_frames: 12
    continuity_risks: ["Watch colour temperature when cutting against cool-toned interior shots; check horizon direction when cutting against another dusk shot"]
  qc_ref: "qc_scan.sh output directory /tmp/probe_hb (probe.json / qc.log / sheet.png)"
  privacy_flags: []

meta:
  model: "<model name and version>"
  prompt_ref: "model-analysis-prompt.md"
  analyzed_at: "2026-11-10"
  analyst: "Zhang San"
  card_version: 1
  status: active
  supersedes: null
  corrections: []

constraints:
  no_expression_copy: true
  theme_neutrality: true
  no_geo_guess: true
  no_identity_guess: true
  no_use_until_cleared: true
```

**Why this one card can serve many topics**: it claims only "no people, no on-screen text, dusk mood, single shot, original wave audio, warm-leaning white balance". A nostalgia theme takes 00:03–00:08 as the opening, a science-explainer theme takes 00:12–00:19 with an overlay, a travel theme takes the first 5 s with a place-name lower third — four themes each write one adaptation record, and not a single word of the card itself changes.

# 素材描述卡（MDC）规范 · `mdc-v1`

> 分类：素材记忆 | 主题：一次视频模型调用产出的结构化素材描述，字段字典与证据约束 | 整理日期：2026-11-10 | 适用：任何需要被理解、检索、跨主题复用的自有/授权视频素材

> ⚠️ 本卷为创作与工程流程参考，**不构成法律意见**；卡片中的授权、肖像、地点与来源信息须人工复核，商用项目请法务复核，详见 `../05-版权法规/`。

---

## 一、设计目标：一次看懂，永久复用

同一段「海边日落空镜」可能同时被「秋日怀旧」「气候科普」「旅游推广」「品牌片尾」四个主题采用。若每次都把视频重新发给模型，四份钱、四份时间、还可能得到四种互相矛盾的描述。MDC 把这件事拆成：

| 原则 | 含义 | 违反后果 |
| --- | --- | --- |
| **一次写全** | 一次模型请求覆盖内容/地点/风格/可用性/时间码事件 | 为不同主题反复请求模型，节省归零 |
| **主题中立** | 卡里只写「素材是什么」，不写「这个主题怎么用」 | 换主题时描述变成噪声，甚至误导选段 |
| **事实与推断分栏** | 每条字段挂证据等级；推断必须给依据 | 模型把「像在三亚」写成事实，后续全链路跟着错 |
| **身份可验证** | 内容哈希 + 技术规格，字节变了自动失效 | 素材已换版本却还在用旧描述，剪出错误内容 |
| **可纠错不覆盖** | 纠错生成 `v+1`，旧版与原因永久保留 | 出错后无法追溯是哪次分析引入的偏差 |

卡片是**描述**不是**评估**：深度风格评估（节奏骨架、切点依据、声音设计意图）属于 `../08-RSI自进化/02`，本卡只回答「这段素材里有什么、可怎么用」。

## 二、证据等级（与 08 卷完全一致）

| 级别 | 定义 | 本卷典型来源 | 能否作为交付依据 |
| --- | --- | --- | --- |
| **E1 客观可复现** | 重跑命令得到相同数值 | SHA-256、ffprobe 规格、`reference_probe.sh` 的切点/响度/YAVG/SATAVG | 可 |
| **E2 可指认事实** | 带时间码可被第三方复核 | 00:03 出现红色路牌、00:12 有人声「这边」、画面内文字 OCR；拍摄记录/授权书/EXIF 亦属此类（标「凭证」） | 可（关键项需 ≥2 处印证） |
| **E3 解释性推断** | 基于 E1/E2 的合理推断 | 「疑似黄昏逆光」「整体偏冷调」「像手持跟拍」「可能适合做开场空镜」 | **否**，只能参考并写明依据与置信度 |
| **E4 猜测/仅描述** | 无画面或无法核实 | 「听说是青岛拍的」「甲方说大概是去年」 | **否**，强制标低置信度，不得进入交付台账 |

**地点与身份特别规则**：`where.place_name` 只能是 E2（画面内可指认地标/文字，或拍摄记录凭证）或留空。禁止仅凭「有海+有椰子树」推断城市名；允许写成 `E3` 的 `environment_semantics`（如「亚热带海滨感」），但那不是地名。这条规则直接对应 `../06-成片审查/02` 中素材台账的准确性要求。

## 三、`mdc-v1` 字段字典

### 3.1 身份层 `identity`（全 E1）

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `material_id` | str | `MID-<sha256 前 12 位小写>`，内容寻址，路径无关 |
| `content_hash` | str | `sha256:<64hex>`；`hash_mode: sampled \| full` |
| `hash_mode` | enum | `sampled`（6 MB 采样，默认）/ `full`（全文件，高一致风险项目用） |
| `size_bytes` / `duration_s` | int / float | 参与哈希与失效判定 |
| `container` `vcodec` `resolution` `fps` `pix_fmt` `acodec` `sample_rate` `channels` | str/num | 取自 ffprobe |
| `aliases` | list[str] | 文件名、项目内代号；**仅检索用，不作为身份** |
| `source_path_hint` | str | 路径提示；缓存**不保存原视频本体** |
| `first_registered` / `last_verified` | ISO date | 登记与最近一次 `verify` 时间 |

子片段另用 `segment_id = sha256(content_hash + "|" + start + "|" + end)[:12]`，并带 `parent_mid`、继承父卡描述、只重写本段差异。裁剪/转码后的新文件是**新素材**，必须重新 `register`。

### 3.2 内容与叙事 `content`（讲了什么）

| 字段 | 内容要求 | 证据 |
| --- | --- | --- |
| `summary` | ≤80 字，主谓宾齐全，不写评价词 | E2 |
| `subjects` | 人/物/场景主体清单；人物只写可指认特征，不做身份猜测 | E2 |
| `actions` | 关键动作与状态变化 | E2 |
| `timeline` | `[{tc:"00:00:03.5", event:"…", evidence:"E2"}]`，按时间码排序；**至少 3 个锚点**，长素材每 15–30 s 一个 | E2 |
| `spoken` | `has_speech` / `language` / `key_lines` / `transcript_ref`（ASR 文本路径） | E2 |
| `onscreen_text` | 画面内文字（招牌、字幕、UI、水印）原文 + 时间码 | E2 |
| `affordances` | **主题中立**的用途标签：`空镜 / 人物表情 / 产品特写 / 动作过程 / 环境气氛 / 数据画面 / 同期声` | E3，须给依据 |
| `notable_absences` | 明确「没有」的东西（无人声、无字幕、无品牌露出），检索时极有价值 | E2 |

### 3.3 拍摄地点与场景 `where`（在哪里拍）

| 字段 | 内容要求 | 证据 |
| --- | --- | --- |
| `setting_type` | `indoor / outdoor / studio / nature / screen_capture / virtual / unknown` | E2 |
| `place_name` | 行政区或地标名；**无 E2 依据必须填 `null`** | E2 凭证 |
| `place_basis` | 依据类型：`画面内文字 / 可识别地标 / EXIF GPS / 拍摄记录 / 甲方书面说明` | E2 |
| `landmarks` | 可指认物（桥梁、招牌、山体轮廓），带时间码 | E2 |
| `environment` | `time_of_day / weather / season / light_direction / light_quality / background / props` | E2 或 E3（写明） |
| `camera` | `position / angle / height / movement / stability` | E2 |
| `geo_hint` | 仅当有凭证时填坐标或行政区，否则 `null` | E2 |
| `inference_note` | 所有 E3 推断集中写这里，附「依据 + 置信度 + 可证伪条件」 | E3 |

### 3.4 风格 `style`（是什么样的）

| 字段 | 内容要求 | 证据 |
| --- | --- | --- |
| `genre` | 素材体裁：`纪实 / 剧情 / 广告 / 屏录 / 监控 / 动画 / 用户生成` | E3 |
| `visual` | `shot_sizes / composition / movement / stability / color_palette / contrast / saturation / white_balance / grain / era_feel` | E2 观察 + E3 概括 |
| `measured` | **E1 客观值**：`shot_median_s / cuts_per_min / integrated_lufs / true_peak_dbtp / yavg / satavg` —— 来自 `scripts/reference_probe.sh` 与 `scripts/qc_scan.sh` | E1 |
| `audio` | `music / ambience / sfx / voice / noise_floor / has_music_bed` | E2 |
| `mood` | 情绪词 ≤3 个，每个必须配一条画面/声音依据 | E3 |
| `rhythm` | 内部节奏描述（镜头长度、运动速度、是否留白） | E3 |
| `style_notes` | **风格类推断强制五段式**，见 §四 | E3 |
| `similarity_caveat` | 「像某种风格」只能作类比，不得写成事实或来源 | E3 |

### 3.5 可用性与合规 `usability`（能不能用）

| 字段 | 说明 |
| --- | --- |
| `provenance` | `origin: self_shot / stock / client / archive / ugc / unknown`；`acquired_from`；`license_ref`（指向凭证文件路径，不内嵌敏感信息） |
| `rights_status` | `cleared / pending / restricted / blocked / unknown`；**`unknown` 与 `blocked` 一律不得进入时间线** |
| `rights_expiry` | 授权到期日；到期只标 `blocked` + 追加日志，**不删卡** |
| `releases` | 肖像同意 / 未成年人监护同意 / 场地许可 / 商标与品牌露出 / 音乐授权，逐项 `yes/no/na/unknown` |
| `quality_issues` | 黑场、静音、抖动、失焦、过曝、口误、水印、音画不同步，带时间码 |
| `edit_notes` | `best_ranges` / `avoid_ranges` / `handles_frames` / `continuity_risks`（与相邻素材的轴线、色温、时段冲突） |
| `qc_ref` | 指向 `qc_scan.sh` 输出目录与审查表行号 |
| `privacy_flags` | 人脸、车牌、门牌、证件、屏幕内个人信息 → 提醒脱敏（见 `../05-版权法规/04`） |

### 3.6 元信息与约束 `meta` / `constraints`

`meta`：`model`（模型名与版本）、`prompt_ref`（用哪版提示词）、`analyzed_at`、`analyst`、`card_version`（从 1 起）、`status: active / superseded / blocked / unverified`、`supersedes`、`corrections[]`（每次纠错写 `时间 / 字段 / 旧值 / 新值 / 依据 / 签字`）。

`constraints`：`no_expression_copy: true`（描述不得抄录受保护表达，长台词只写要点与位置）、`theme_neutrality: true`（禁止出现具体主题名/项目名）、`no_geo_guess: true`、`no_identity_guess: true`。

## 四、风格说明强制约束（沿用 08 卷）

`style.style_notes` 里每一条都必须是五段式，缺一段整条作废：

| 段 | 要求 |
| --- | --- |
| ① 观察 | 具体、带时间码或可复现数值 |
| ② 依据 | 证据等级 + 来源（抽帧第几行 / 探测日志哪个字段） |
| ③ 推断 | 由观察得到的风格判断，明确写「这是推断」 |
| ④ 动作项 | 对剪辑有什么用（选段、调色方向、节奏搭配） |
| ⑤ 置信度 | 高/中/低 + 一句理由 |

> **示范**：`S1 光线与色调`｜① 00:04–00:11 天空占画面约 2/3，主体边缘有轮廓光，YAVG 由 118 降到 76（逆光渐暗）｜② E1 `signalstats` 输出 + E2 抽帧拼图第 2 行｜③ 推断为黄昏逆光的暖冷对比，属自然光而非布光｜④ 作开场空镜时不再叠加暖色 LUT，避免与后续室内镜头色温断裂｜⑤ 中：仅一段素材，未见全片色彩策略。

**被丢弃的反例**：「画面很有质感、色调高级」「适合做情绪片」——无依据、无置信度，且「适合做情绪片」是主题判断，应写到 L2 主题适配层，不进 MDC。

## 五、八条校验规则（`material_cache.py validate`）

| # | 规则 | 失败处理 |
| --- | --- | --- |
| V1 | `mdc_version == "mdc-v1"`、`material_id` 格式合法 | 拒绝登记 |
| V2 | 四组必填节 `content / where / style / usability` 齐全，`meta` 存在 | 拒绝登记 |
| V3 | `identity.content_hash` 与实际文件哈希一致 | 拒绝登记，重跑 `fingerprint` |
| V4 | `content.summary` ≤80 字且非空；`timeline` ≥3 个锚点且时间码递增 | 拒绝登记 |
| V5 | `where.place_name != null` 时必须有非空 `place_basis` | 拒绝登记（防无依据地名） |
| V6 | `style.style_notes` 每条含 `观察/依据/推断/动作项/置信度` 五个键 | 该条作废，全卡标 `unverified` |
| V7 | `rights_status` 为 `unknown/blocked` 时 `constraints` 必须含 `no_use_until_cleared: true` | 标 `blocked`，剪辑流程阻断 |
| V8 | `constraints.theme_neutrality == true` 且四组字段中不出现 `theme/主题/项目代号` 等主题词 | 警告并要求人工确认 |

V8 用关键词粗筛，会漏也会误报，**它只是提示，不替代人工通读**。

## 六、填写工作流

1. `fingerprint` 拿身份与 ffprobe 规格 → 自动填入 `identity`（E1，不经过模型）。
2. 本地客观探测：`reference_probe.sh` 拿切点、镜头时长、响度、YAVG/SATAVG、抽帧拼图 → 填 `style.measured`（E1）。
3. 用 `模板/模型分析提示词.md` 发**一次**视频理解请求，要求结构化返回 → 人工逐条核对，把模型输出拆进 `content / where / style / usability`。
4. 每条标证据等级；所有 E3 推断补五段式说明；地点与身份无依据一律 `null`。
5. 授权信息从凭证文件填，**不采信模型猜测**；`privacy_flags` 人工过一遍。
6. `validate` → `register` → 此后任意主题只读卡。

## 七、常见错误与排查

| 错误 | 正确做法 |
| --- | --- |
| 卡片里写「适合秋日怀旧主题」 | 写进 L2 主题适配层；MDC 只写 `affordances: [空镜, 环境气氛]` |
| 模型说「像在三亚」，照抄成 `place_name` | `place_name: null`；把「亚热带海滨感」写进 `inference_note` 标 E3 |
| 素材重新导出了一版，仍用旧卡 | 内容哈希变化 → `lookup` 判 `STALE`，重新登记；旧卡转 `superseded` 保留 |
| 描述里大段抄台词 | `key_lines` 只写要点 + 时间码，`transcript_ref` 指向转写文件 |
| 授权到期把卡片删了 | 标 `blocked` + 追加日志，保留历史可追溯 |
| 用均值描述节奏 | 用 `shot_median_s`（长尾分布下均值失真），与 08 卷口径一致 |
| 不同主题各自让模型重看一遍 | 命中即只读；确需补充先试抽帧/ASR/ffprobe |

## 八、速查清单

- [ ] `identity` 全为 E1，哈希与文件一致
- [ ] `content` 有摘要、主体、≥3 个时间码锚点、口语与画面文字
- [ ] `where` 有场景类型与环境；地名无凭证则 `null`
- [ ] `style` 有 E1 实测值 + 五段式风格说明，情绪词有依据
- [ ] `usability` 授权状态明确，隐私项已过，`quality_issues` 带时间码
- [ ] `meta` 记录模型版本、提示词版本、分析日期与签字
- [ ] `constraints` 四项开关齐全
- [ ] 通过 V1–V8，全卡主题中立、可跨主题复用

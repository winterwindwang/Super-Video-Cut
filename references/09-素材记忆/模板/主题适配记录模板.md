# 主题适配记录模板（L2 层）

> 分类：素材记忆 | 主题：一素材 × 一主题的选段、叙事角色、理由与效果反馈 | 整理日期：2026-11-10 | 适用：任一主题采用已登记素材时填写；机器读部分由 `material_cache.py use` 写入 `缓存库/themes/<MID>.csv`

> ⚠️ 本卷为创作与工程流程参考，**不构成法律意见**；`rights_scope_check` 须按授权凭证逐主题核对，商用项目请法务复核。

## 模板（复制一段填一次）

```markdown
## 适配记录：<THEME-ID> / <MID>

| 字段 | 内容 |
| --- | --- |
| theme_id | T-YYYY-<短名> |
| theme_title | |
| adapted_at | 2026-11-10T15:20:00 |
| material_id / summary | MID-xxxxxxxxxxxx / （从 MDC 抄 80 字摘要，不重写） |
| clip_ranges | 00:00:03-00:00:08 |
| narrative_role | 开场钩子 / 铺垫 / 论证画面 / 情绪高点 / 转场 / 收束 / B-roll / 证据材料 |
| rationale ① 观察 | |
| rationale ② 依据 | （必须引用 MDC 字段名或时间码，如 `content.timeline[1]`、`style.measured`） |
| rationale ③ 推断 | （明确写「这是推断」） |
| rationale ④ 动作项 | （具体参数：时长、变速、调色、字幕、音频） |
| rationale ⑤ 置信度 | 高 / 中 / 低 + 一句理由 |
| edit_directives | |
| audio_handling | 用原声 / 静音 / 配乐 / 解说覆盖 |
| rights_scope_check | in_scope / needs_recheck / out_of_scope |
| conflicts_with | （通常填「无」；用法不同不算冲突） |
| outcome | （发布后回填：采用/弃用 + 原因 + 数据摘要） |
| feedback_ref | ../../08-RSI自进化/案例库/<CASE-ID>/自进化记录.md |
```

## 填写示范（虚构，演示格式）

| 字段 | 内容 |
| --- | --- |
| theme_id | `T-2026-秋日怀旧` |
| theme_title | 《那年夏天之后》30 s 短片 |
| adapted_at | 2026-11-10T15:10:00 |
| material_id / summary | `MID-9f3c1a7b02de` / 黄昏海边固定机位空镜，镜头缓慢右移，浪反复拍打礁石，画面内无人物与文字 |
| clip_ranges | `00:00:03-00:00:08` |
| narrative_role | 开场钩子（情绪铺垫） |
| ① 观察 | MDC 记 00:03–00:08 为空镜，无人物、无字幕、无品牌物；`style.measured` 记 `cuts_per_min=0.0`、海浪原声连续 |
| ② 依据 | `content.notable_absences`、`content.timeline[1]`、`style.measured.shot_median_s`（E1/E2，来源 MDC） |
| ③ 推断 | 这是推断：该段不承担信息负载，适合作为无干扰的情绪入口 |
| ④ 动作项 | 剪入 5 s，慢放 80%，前留 1 s 黑场，不叠字幕，海浪原声 −6 dB 起、2 s 淡入 |
| ⑤ 置信度 | 高：画面事实可复核；同主题此前 2 次同类用法评审通过 |
| edit_directives | 不加暖色 LUT（MDC `style_notes[0]` 已提示色温断裂风险）；首帧不做缩放 |
| audio_handling | 用原声（海浪），2 s 淡入，配乐从 00:05 进 |
| rights_scope_check | `in_scope`（自有拍摄，授权凭证覆盖商业与非商业用途） |
| conflicts_with | 无（另一主题取 00:12–00:19，片段与剪法各自独立） |
| outcome | 待回填 |
| feedback_ref | 待回填 |

## 硬规则

1. **不回写 MDC**：本记录里的任何判断都不得修改 `cards/<MID>.yaml`。发现 MDC 事实有误，走 `verify` + 人工纠错生成 `card_version+1`。
2. **依据必须可指认**：`rationale ②` 引用 MDC 字段或时间码；「感觉不错」「挺搭」一律作废。
3. **逐主题查授权**：`rights_scope_check != in_scope` 时该主题不得进入时间线，走 `../../05-版权法规/` 复核。
4. **只追加**：弃用写 `outcome: 弃用 + 原因`，不删除记录；反例是回归集资产（见 `../../08-RSI自进化/06`）。
5. **片段合法**：`clip_ranges` 必须落在 `identity.duration_s` 内，且与 `edit_notes.avoid_ranges` 不重叠；重叠需在 `rationale ④` 说明理由。
6. **换版不迁移**：素材字节变化产生新 MID 时，旧适配记录保留但不自动套用，须逐条人工确认。

## 与命令的对应

```bash
PY="scripts/material_cache.py"
V="D:/素材库/2026-09/海边日落_原片.mp4"

# 机器读记录（写 themes/<MID>.csv + usage.csv + audit.log）
python "$PY" use "$V" --theme "T-2026-秋日怀旧" --clip "00:00:03-00:00:08" --note "开场空镜"
python "$PY" use "$V" --theme "T-2026-气候科普" --clip "00:00:12-00:00:19" --note "云层示意"

# 查看该素材被哪些主题用过
python "$PY" themes "$V"
```

本 Markdown 模板用于需要写详细 `rationale` 与 `edit_directives` 的场景；简单复用直接用命令即可，两者以 `theme_id + clip_ranges` 对应。

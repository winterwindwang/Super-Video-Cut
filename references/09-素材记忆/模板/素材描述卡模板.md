# 素材描述卡 · 人读版填写指南与示范

> 分类：素材记忆 | 主题：MDC 人读版填写指南、逐字段说明与完整填写示范 | 整理日期：2026-11-10 | 适用：人工填写/复核描述卡；机器读版本用同目录 `素材描述卡模板.yaml`

> ⚠️ 本卷为创作与工程流程参考，**不构成法律意见**；示范中的地点、授权与反馈均为虚构演示，商用项目须以凭证为准。

## 一、怎么用这份文件

| 文件 | 用途 |
| --- | --- |
| `素材描述卡模板.yaml` | **机器读**：复制后填写，`validate` + `register` 入库 |
| 本文件 | **人读**：解释每个字段怎么填，给一条完整示范 |
| `模型分析提示词.md` | MISS 时那「一次」模型请求用的提示词 |
| `../01-素材描述卡规范.md` | 字段字典、证据等级与 V1–V8 校验规则的权威版本 |

填写顺序：`identity`（工具自动）→ `style.measured`（本地探测）→ 一次模型请求 → 人工核对四组字段 → `usability` 授权与隐私 → `meta` → `constraints` → `validate`。

## 二、逐字段填写要点

| 组 | 最容易填错的地方 | 判据 |
| --- | --- | --- |
| `content.summary` | 写成「唯美的海边画面」 | ≤80 字、主谓宾齐全、无评价词：「黄昏海边固定机位空镜，镜头缓慢右移，浪反复拍打礁石」 |
| `content.timeline` | 只有开头结尾两个锚点 | ≥3 个；>60 s 素材每 15–30 s 一个；每条带 `tc` + `event` + `evidence` |
| `content.affordances` | 写「适合怀旧开场」 | 只能填中立标签；用途结论去 `主题适配记录模板.md` |
| `where.place_name` | 凭「像三亚」填地名 | **无画面文字/地标/拍摄记录一律 `null`**；印象写 `inference_note` 并标 E3 |
| `where.environment` | 把「黄昏」当确定事实 | 若只是光线推断，标 E3 并写可证伪条件 |
| `style.measured` | 抄模型给的估算 | 必须由 `reference_probe.sh` / `ffprobe` 的 E1 数值覆盖 |
| `style.style_notes` | 写成「色调高级」 | 五段式齐全：观察 / 依据 / 推断 / 动作项 / 置信度 |
| `usability.rights_status` | 模型说「应该没问题」 | 只能由人工按授权凭证填；`unknown` 一律阻断 |
| `usability.privacy_flags` | 忘了车牌/门牌 | 逐项过一遍画面，标时间码 |
| `meta` | 不记模型版本 | 模型名与版本、提示词版本、分析日期、签字人必填 |
| `constraints` | 删掉 `no_use_until_cleared` | 授权未清时此开关是硬阻断 |

```yaml
  theme_neutrality: true

```

**为什么这张卡能服务很多主题**：它只声明「无人物、无文字、黄昏感、单镜头、海浪原声、色温偏暖」。怀旧主题取 00:03–00:08 做开场、科普主题取 00:12–00:19 加标注、旅游主题取首 5 s 叠地名条——四个主题各自写一条适配记录，卡本身一个字都不用改。
